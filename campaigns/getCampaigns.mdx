title: "Get Campaigns"
description: "Retrieve all campaigns available in your workspace with pagination and search support."
openapi: "GET /api/campaigns"
---

## Overview

Retrieve a paginated list of all campaigns in your workspace. This endpoint supports pagination and search, making it easy to browse, monitor, or locate specific campaigns.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to access Campaigns

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField query="page" type="integer">
Page number for pagination. Default is `1`.
</ParamField>

<ParamField query="limit" type="integer">
Number of campaigns to return per page. Default is `10`.
</ParamField>

<ParamField query="search" type="string">
Optional search term to filter campaigns by name.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/campaigns?page=1&limit=10&search=sales' \
  --header 'Authorization: Bearer {{authToken}}'
```

</RequestExample>

## Error Handling

- **400 Bad Request** – Invalid query parameters.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to access campaigns.
- **500 Internal Server Error** – Unexpected server error.

<Note>

This endpoint supports **pagination** and **search**. If no search term is provided, all campaigns in the workspace are returned.

</Note>

<Check>

Use the returned **Campaign ID** with:

- `GET /api/campaigns/{id}` to retrieve campaign details.
- `PATCH /api/campaigns/{id}` to update a campaign.
- `DELETE /api/campaigns/{id}` to delete a campaign.
- `POST /api/campaigns/{id}/start` to start a campaign.
- `POST /api/campaigns/{id}/stop` to stop a campaign.

</Check>
