A weya campaign calls a list of contacts with your voice agent, inside the schedule and retry rules you set. Each campaign has its own calling numbers, calling days and hours, retry settings, contact list and result destinations. In the API and in webhooks, a campaign is called a **batch**.

## Before you start

- A voice agent assigned as the **outbound agent** of at least one phone number. See [Connect a phone number](/phonenumbers/addphonenumber).
- A contact file in CSV or Excel format. See [Contact file format](#contact-file-format).

## Create the campaign

<Steps>
  <Step title="Start a new campaign">
    Go to **Campaigns** and click **Create Campaign**. Give the campaign a name you'll recognise in reports.
  </Step>
  <Step title="Choose calling numbers">
    Under **Calling Numbers**, select one or more of your phone numbers. Each call is handled by the outbound agent assigned to the number it is made from.
  </Step>
  <Step title="Set the calling schedule">
    - **Calling days**: the days of the week calls can be placed.
    - **Timezone**: the timezone the schedule follows, for example `(GMT+5:30) Chennai, Kolkata, Mumbai, New Delhi`. Use your contacts' timezone, not yours.
    - **Start and end time**: the daily calling window, for example 09:00 to 17:00.

    Calls are placed only inside this window. Outside it the campaign waits and carries on when the window next opens.
  </Step>
  <Step title="Set retry rules">
    - **Max attempts per contact**: how many times a contact can be called, from 1 to 10.
    - **Delay between attempts**: how long to wait before calling the same contact again, from 5 to 1440 minutes.
  </Step>
  <Step title="Choose where results go">
    Under the CRM options, choose where each call's result is sent: a [webhook](/integration/webhooks), a [CRM](/integration/crmintegration) or a Google Sheet.
  </Step>
  <Step title="Allow inbound calls (optional)">
    Turn on **Allow inbound calls on selected phone numbers** if contacts may call these numbers back. The numbers' inbound agent answers those calls.
  </Step>
  <Step title="Upload contacts">
    1. Select the **country code** used to validate numbers that don't include one, for example `+91` for India.
    2. Add any **mandatory template variables**: columns every row must have a value for.
    3. Upload your file.
  </Step>
  <Step title="Create the campaign">
    Review the settings and click **Create Campaign**. The campaign appears in your campaign list with its progress and status.
  </Step>
</Steps>

## Contact file format

| Rule | Detail |
| --- | --- |
| File type | `.csv`, `.xls` or `.xlsx`, up to 50 MB. Excel files use the first sheet |
| Header row | Required |
| `phoneNumber` column | Required, one number per row |
| Other columns | Optional. Each becomes a variable your agent can use, for example `customer_name` |
| Duplicates | If a number appears twice, only the first row is kept |
| Encoding | UTF-8 |

```csv contacts.csv
phoneNumber,customer_name,amount_due,due_date
+919800000001,Asha,4500,2026-12-05
+919800000002,Rahul,1200,2026-12-07
```

<Tip>
  Name your columns exactly as the variables in your agent's prompt, and mark the ones the agent can't do without as mandatory. Rows missing them are rejected at upload instead of producing a broken call.
</Tip>

## Manage a running campaign

From the campaign list you can **pause** and resume a campaign, **edit** its settings, **export** its data and **delete** it. Deleting a campaign removes its call records permanently. To change a running campaign's settings, pause it first.
