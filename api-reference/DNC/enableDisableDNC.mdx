---
title: "Enable/Disable DNC"
description: "Turn your organization's DNC setting on or off."
api: "POST /api/dnc/enable-disable"
---

## Overview

Turn your organization's DNC setting on or off. While it is on, campaigns can be created or updated with `enableDNC: true`; while it is off, sending `enableDNC: true` is rejected.

This setting doesn't decide whether numbers on the DNC list are called. Numbers on your organization's DNC list are skipped in every campaign whether the setting is on or off. To allow a number to be called again, remove it with [Remove from DNC List](/api-reference/DNC/removeFromDNC).

## Prerequisites
- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField body="enable" type="boolean" required>
`true` to turn the setting on, `false` to turn it off. Must be a JSON boolean, not a string.
</ParamField>

<RequestExample>
```bash cURL
curl --location 'https://api.weya.live/backend/api/dnc/enable-disable' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "enable": true
  }'
```
</RequestExample>

## Response

<ResponseExample>
```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "DNC setting updated successfully",
  "errorMessage": null,
  "data": []
}
```
</ResponseExample>

<ResponseField name="status" type="boolean" required>
`true` when the setting was saved.
</ResponseField>

<ResponseField name="message" type="string" required>
`DNC setting updated successfully`.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Enable field must be a boolean`: `enable` is missing or not `true`/`false`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Organization not found`.
- **500 Internal Server Error** – Unexpected server error.
