---
title: "Remove from DNC List"
description: "Remove a phone number from your organization's Do Not Call (DNC) list."
api: "DELETE /api/dnc/delete/{id}"
---

## Overview
Permanently remove a phone number from your organization's Do Not Call list. Once removed, the number can be called again in future campaigns. You can only delete DNC entries that belong to your organization.

## Prerequisites
- An API key for your workspace
- Valid DNC record ID that belongs to your organization

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the DNC entry to delete: the `_id` from [Get DNC List](/api-reference/DNC/getDNCList).
</ParamField>

<RequestExample>
```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/dnc/delete/64e5f12345abcdef98765432' \
  --header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

## Response

<ResponseExample>
```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "DNC record deleted successfully",
  "errorMessage": null,
  "data": []
}
```
</ResponseExample>

<ResponseField name="message" type="string" required>
Success message confirming the DNC record was deleted.
</ResponseField>

<ResponseField name="status" type="boolean" required>
Indicates whether the operation was successful.
</ResponseField>

<ResponseField name="code" type="integer" required>
HTTP status code (200 for success).
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `DNC record not found or you are not authorized to delete it`: no entry with this ID exists in your organization.
- **500 Internal Server Error** – Unexpected server error, including an `id` that isn't a valid ID.

<Warning>
This action is permanent. Once a DNC record is deleted, the phone number can be called again in future campaigns. Make sure you have the correct DNC record ID before deleting.
</Warning>
