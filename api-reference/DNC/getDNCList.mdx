---
title: "Get DNC List"
description: "Retrieve a paginated list of the phone numbers on your organization's Do Not Call (DNC) list."
api: "GET /api/dnc/list"
---

## Overview
List the phone numbers on your organization's Do Not Call list, newest first. The list covers the whole organization, not only entries added by the user who owns the API key.

## Prerequisites
- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page number.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Number of entries per page.
</ParamField>

<ParamField query="search" type="string">
Case-insensitive text matched against the phone number, `type` and `requestUUID`. Partial matches are returned. The text is read as a regular expression, so leave out a leading `+` when searching for a number.
</ParamField>

<RequestExample>
```bash cURL
curl --location 'https://api.weya.live/backend/api/dnc/list?page=1&limit=10&search=2125551234' \
  --header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

<ResponseField name="data.dncList" type="array[object]" required>
The DNC entries on this page.
</ResponseField>

<ResponseField name="data.dncList[]._id" type="string" required>
DNC entry ID. Use it to remove the entry with [Remove from DNC List](/api-reference/DNC/removeFromDNC).
</ResponseField>

<ResponseField name="data.dncList[].phoneNumber" type="string" required>
The phone number, as it was added.
</ResponseField>

<ResponseField name="data.dncList[].type" type="string">
`Call`, `Email` or `Whatsapp`, if set.
</ResponseField>

<ResponseField name="data.dncList[].orgId" type="string" required>
Your organization ID.
</ResponseField>

<ResponseField name="data.dncList[].batchId" type="string">
Campaign the entry is linked to, if it was added from a call.
</ResponseField>

<ResponseField name="data.dncList[].requestUUID" type="string">
Call the entry is linked to, if any.
</ResponseField>

<ResponseField name="data.dncList[].callRecording" type="string">
Recording of the linked call, if available.
</ResponseField>

<ResponseField name="data.dncList[].transcription" type="string">
Transcription of the linked call, if available.
</ResponseField>

<ResponseField name="data.dncList[].createdAt" type="string" required>
When the entry was added (ISO 8601).
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.
