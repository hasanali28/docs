---
title: "Get Agents"
description: "Retrieve your AI agents with pagination and search."
api: "GET /api/agents"
---

## Overview

List the agents created by the user who owns the API key, newest first. By default the list contains voice agents and leaves out multi-stage agents; use the query parameters below to change that.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
  Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="page" default="1" type="integer">
  Page number.
</ParamField>

<ParamField query="limit" default="10" type="integer">
  Number of agents per page, up to 1000.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive text matched against the agent name. Partial matches are returned.
</ParamField>

<ParamField query="channel_type" default="voice" type="string">
  `voice` or `chat`. Any other value lists voice agents.
</ParamField>

<ParamField query="gender" type="string">
  Only return agents with this gender: `Male` or `Female`.
</ParamField>

<ParamField query="includeMultiStage" default="false" type="boolean">
  `true` to include multi-stage agents.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/agents?page=1&limit=10&search=sales' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data.agents" type="array[object]" required>
  The agents on this page, with summary fields only. Use [Get Agent By ID](/api-reference/Agents/getAgentById) for an agent's full configuration.
</ResponseField>

<ResponseField name="data.agents[]._id" type="string">
  Agent ID.
</ResponseField>

<ResponseField name="data.agents[].agent_name" type="string">
  Agent name.
</ResponseField>

<ResponseField name="data.agents[].gender" type="string">
  `Male` or `Female`.
</ResponseField>

<ResponseField name="data.agents[].conversationType" type="string">
  `single_prompt`, `static_voice_blaster`, `dynamic_voice_blaster` or `multi_stage`.
</ResponseField>

<ResponseField name="data.agents[].channel_type" type="string">
  `voice` or `chat`. Older voice agents may not have this field.
</ResponseField>

<ResponseField name="data.agents[].latest_version" type="integer">
  Number of the agent's latest saved version.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
  Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Check>
  Use the returned agent ID with:

  - `GET /api/agents/{id}` to retrieve the agent's full configuration.
  - `PATCH /api/agents/{id}` to update an agent.
  - `DELETE /api/agents/{id}` to remove an agent.
</Check>
