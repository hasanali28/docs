## Overview

Create a new AI voice agent for your workspace.

When creating an agent, you can configure its basic details, conversation flow, welcome message, system prompt, knowledge bases, tools, call settings, and call metrics. Once created, the agent can be updated, published, or assigned to other services using their respective endpoints.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to create agents

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/agents' \
  --header 'Authorization: Bearer {{authToken}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "agent_name": "Customer Support Agent",
    "gender": "Female",
    "voice": "voice_id",
    "conversationType": "single_prompt",
    "welcomeMessage": "Hello! How can I help you today?",
    "systemMessage": {
      "prompt": "You are a helpful customer support assistant."
    },
    "knowledgeBase": [],
    "tools": {},
    "callSetting": {},
    "call_metrics": []
  }'
```

</RequestExample>

## Request Body

<ParamField body="agent_name" type="string" required>
Name of the AI agent.
</ParamField>

<ParamField body="gender" type="string" required>
Voice gender for the agent.
</ParamField>

<ParamField body="voice" type="string" required>
Voice to use for conversations.
</ParamField>

<ParamField body="conversationType" type="string" required>
Conversation mode for the agent.
</ParamField>

<ParamField body="welcomeMessage" type="string">
The first message spoken when the conversation starts.
</ParamField>

<ParamField body="systemMessage" type="object" required>
Instructions that define how the AI behaves during conversations.
</ParamField>

<ParamField body="knowledgeBase" type="array">
Knowledge Bases attached to the agent.
</ParamField>

<ParamField body="tools" type="object">
Tools and integrations available during calls.
</ParamField>

<ParamField body="callSetting" type="object">
Voice and runtime settings for the agent.
</ParamField>

<ParamField body="call_metrics" type="array">
Metrics to extract after each call.
</ParamField>

## Error Handling

- **400 Bad Request** – Invalid request body.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to create agents.
- **409 Conflict** – An agent with the same configuration already exists.
- **500 Internal Server Error** – Unexpected server error.

<Note>

During agent creation, you can configure:

- Welcome Message
- System Prompt
- Knowledge Bases
- Tools & Integrations
- Call Settings
- Call Metrics

Each of these configurations is included as part of the request body.

</Note>

<Check>

After creating an agent, you can:

- Retrieve it using `GET /api/agents/{id}`
- Update it using `PATCH /api/agents/{id}`
- Publish it using the Publish Agent endpoint
- Assign it to phone numbers or campaigns using their respective endpoints

</Check>
