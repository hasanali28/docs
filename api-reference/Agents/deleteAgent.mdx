---
title: "Delete Agent"
description: "Permanently delete one of your AI agents."

---

## Overview

Permanently delete an agent created by the user who owns the API key, together with all its saved versions and unsaved drafts.

The API doesn't check whether phone numbers or campaigns still use the agent, and doesn't unassign it from them. Assign another agent to those phone numbers before deleting, or their calls won't have an agent.

<Warning>

Deleting an agent can't be undone.

</Warning>

## Prerequisites

- An API key for your workspace
- The agent's ID, from [Get Agents](/api-reference/Agents/getAgents)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
  ID of the agent to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/agents/687b1c2ab7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Agent deleted successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

<ResponseField name="message" type="string" required>
`Agent deleted successfully`.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `id` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Agent not found`: the agent doesn't exist or wasn't created by the user who owns the API key.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Knowledge bases, phone numbers and call history are not deleted with the agent.

</Note>
