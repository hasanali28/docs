## Overview

The **Create Agent** endpoint creates a new AI voice agent.

When creating an agent, you configure the basic settings that define how the agent behaves during calls. These settings are the same as those available in the Weya AI dashboard.

A typical agent configuration includes:

- Voice selection
- Welcome message
- System prompt
- Knowledge bases
- Tools
- Call settings
- Call metrics

Once the agent is created, you can update its configuration or publish it using the respective endpoints.

## Request

```bash
curl -X POST https://{{baseUrl}}/api/agents \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_name":"Customer Support",
    "voice":"voice_id",
    "welcomeMessage":"Hello! How can I help you today?",
    "systemMessage":{
      "prompt":"You are a helpful customer support assistant."
    },
    "knowledgeBase":[],
    "tools":{},
    "callSetting":{},
    "call_metrics":[]
  }'
```

---

## Request Body

### Agent Information

| Field | Type | Required | Description |
|------|------|----------|-------------|
| `agent_name` | string | Yes | Name of the agent. |
| `voice` | string | Yes | Voice used by the agent. |

### Call Flow

These settings define how the conversation starts.

| Field | Type | Description |
|------|------|-------------|
| `welcomeMessage` | string | First message spoken by the agent. |
| `systemMessage` | object | Instructions that define the agent's behaviour during conversations. |

### Knowledge Base & Tools

These settings allow the agent to access additional information and actions.

| Field | Type | Description |
|------|------|-------------|
| `knowledgeBase` | array | Knowledge bases attached to the agent. |
| `tools` | object | Tools available during conversations. |

### Call Settings

Controls the behaviour of calls.

Examples include:

- Language detection
- Voicemail handling
- IVR
- Call scheduling
- Speech settings
- Voice settings
- Memory
- LLM configuration

### Call Metrics

Define the information that should be extracted after each call.

Each metric contains:

- Metric name
- Data type
- Description

## Notes

- The **Welcome Message** is the first message spoken by the agent.
- The **System Prompt** controls how the agent responds during conversations.
- **Knowledge Bases** provide information that the agent can reference while answering users.
- **Tools** allow the agent to perform actions during a call.

- **Call Metrics** define the information extracted after each completed call.

## FAQ

### What is required to create an agent?

At minimum, provide an agent name, a voice, and a system prompt.

### Can I attach a knowledge base while creating the agent?

Yes. You can attach one or more knowledge bases during agent creation.

### Can I configure call settings?

Yes. Call behaviour such as voicemail, IVR, scheduling, memory, and voice settings can be configured using the `callSetting` object.

### What are call metrics?

Call metrics define the structured information that should be extracted from completed conversations.

### Can I update the agent later?

Yes. After creating the agent, you can modify its configuration using the **Update Agent** endpoint.
