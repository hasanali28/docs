## Overview

Create a WhatsApp agent for the user who owns the API key. Optionally attach it to one of your WhatsApp integrations with `phoneNumberId`; you can also attach it later with [Assign Agent to WhatsApp Number](/api-reference/WhatsApp/assignAgentToWhatsAppNumber).

Tools, templates, analysis metrics and memory settings are easiest to set up in the dashboard after the agent exists.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField body="agentName" type="string" required>
Name of the agent.
</ParamField>

<ParamField body="systemMessage" type="string" required>
The agent's instructions (prompt).
</ParamField>

<ParamField body="sessionTimeout" type="integer" required>
Minutes of user inactivity after which a conversation ends. The dashboard allows 1 to 360; the API only requires a value.
</ParamField>

<ParamField body="phoneNumberId" type="string">
Integration ID (`_id` from [Get WhatsApp Numbers](/api-reference/WhatsApp/getWhatsAppNumbers)) to attach the agent to.
</ParamField>

<ParamField body="gender" type="string">
`Male`, `Female` or `Other`. Used for verb forms in some languages.
</ParamField>

<ParamField body="selectedLanguage" type="array[string]">
Language codes the agent speaks.
</ParamField>

<ParamField body="rag" type="string">
Knowledge base to answer from: the `vectorDbCollection` of one of your knowledge bases, from [Get Knowledge Bases](/api-reference/KnowledgeBase/getKnowledgeBases).
</ParamField>

<ParamField body="variables" type="array[object]">
  Variables the agent uses.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/save-whatsapp-agent' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "agentName": "Support Assistant",
    "systemMessage": "You are a helpful customer support assistant.",
    "sessionTimeout": 30,
    "gender": "Female",
    "selectedLanguage": ["en-IN"],
    "phoneNumberId": "6891f1d0c45d123456789abc"
  }'
```

</RequestExample>

## Response

<ResponseExample>

```json 201 Created
{
  "status": true,
  "code": 201,
  "message": "Whatsapp agent created successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

<ResponseField name="data" type="array">
Always empty: the response doesn't include the new agent or its ID. Find it with [Get WhatsApp Agents](/api-reference/WhatsApp/getWhatsAppAgents) (most recently edited first).
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request**
  - `Agent name, system message, and session timeout are required`.
  - `Invalid Phone Number ID`.
  - `Only one send_whatsapp_start_message tool is allowed`.
- **401 Unauthorized** – Missing or invalid API key.
- **403 Forbidden** – The request sets `settings.cross_memory`, which only super admins can change.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
