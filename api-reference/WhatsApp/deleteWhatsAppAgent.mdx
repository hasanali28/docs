## Overview

Permanently delete a WhatsApp agent created by the user who owns the API key.

The API doesn't unassign the agent from a WhatsApp number. Remove it first with [Remove Agent from WhatsApp Number](/api-reference/WhatsApp/removeAgentFromWhatsAppNumber), or assign another agent, so the number isn't left pointing at a deleted agent.

<Warning>
  This can't be undone.
</Warning>

## Prerequisites

- An API key for your workspace
- The agent's ID, from [Get WhatsApp Agents](/api-reference/WhatsApp/getWhatsAppAgents)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="agentId" type="string" required>
ID of the WhatsApp agent to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/whatsapp/delete-whatsapp-agent/6894a98a7fcde123456789ab' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Whatsapp agent deleted successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Agent ID`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `WhatsApp agent not found`: it doesn't exist, is already deleted, or wasn't created by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
