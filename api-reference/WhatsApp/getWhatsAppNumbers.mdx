## Overview

List the WhatsApp numbers connected by the user who owns the API key, with the agent assigned to each. The list isn't paginated.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/whatsapp-number' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Fetch phone number details successfully",
  "errorMessage": null,
  "data": [
    {
      "_id": "68920d9c56c1a123456789ab",
      "phoneNumber": "+15551234567",
      "provider": "AI_SENSY",
      "plan": "basic",
      "token": "YOUR_AISENSY_API_TOKEN",
      "whatsappAgentId": { "_id": "68920ea456c1a123456789cd", "agentName": "Support Assistant" },
      "createdAt": "2026-07-21T09:15:30.000Z"
    }
  ]
}
```

</ResponseExample>

<ResponseField name="data" type="array[object]">
Your WhatsApp numbers. Empty if you have none.
</ResponseField>

<ResponseField name="data[]._id" type="string">
Integration ID. Use it as `phoneNumberId` in the other WhatsApp endpoints.
</ResponseField>

<ResponseField name="data[].phoneNumber" type="string">
The WhatsApp number.
</ResponseField>

<ResponseField name="data[].plan" type="string">
`basic` or `pro`.
</ResponseField>

<ResponseField name="data[].whatsappAgentId" type="object | null">
The assigned agent as `{ _id, agentName }`, or `null`.
</ResponseField>

<ResponseField name="data[].token" type="string">
The stored AiSensy token, in plain text. Don't log the response.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
