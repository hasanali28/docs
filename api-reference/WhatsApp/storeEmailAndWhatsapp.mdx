---
title: "Store WhatsApp Conversation Log"

api: "POST /api/whatsapp/store-email-and-whatsapp"
---

## Overview

Save messages of a WhatsApp conversation so they appear in your WhatsApp logs. Messages are added to the conversation between the user's number and your number; the conversation is created if it doesn't exist yet. Only WhatsApp is supported.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="msg_type" type="string">
`outbound` or `inbound`. Can be sent in the query or in the body.
</ParamField>

<ParamField query="service" type="string">
Must be `whatsapp`. Can be sent in the query or in the body.
</ParamField>

<ParamField body="user_phone_number" type="string" required>
  The customer's number.
</ParamField>

<ParamField body="api_phone_number" type="string" required>
  Your WhatsApp number.
</ParamField>

<ParamField body="logs" type="array[object]">
  The messages to add. Sent as is.
</ParamField>

<ParamField body="agent_id" type="string">
  ID of the agent in the conversation.
</ParamField>

<ParamField body="template_id" type="string">
  Template name used in the conversation.
</ParamField>

<ParamField body="call_id" type="string">
  Related call ID.
</ParamField>

<ParamField body="sid" type="string">
  Conversation or session ID.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/store-email-and-whatsapp?msg_type=outbound&service=whatsapp' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "user_phone_number": "+919876543210",
    "api_phone_number": "+15551234567",
    "logs": []
  }'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Logs stored successfully",
  "errorMessage": null,
  "data": {}
}
```

</ResponseExample>

<ResponseField name="data" type="object">
The stored conversation record.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request**
  - `Valid msg_type (outbound/inbound) is required`.
  - `Only service=whatsapp is supported`.
  - `user_phone_number and api_phone_number are required`.
- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
