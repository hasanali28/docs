---

## Overview

List the WhatsApp agents created by the user who owns the API key, most recently edited first. The list isn't paginated. Templates aren't included; use [Get WhatsApp Agent By ID](/api-reference/WhatsApp/getWhatsAppAgentById) for the full configuration.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/get-whatsapp-agent' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,

    {

      "gender": "Female",
      "systemMessage": "You are a helpful customer support assistant.",
      "selectedLanguage": ["en-IN"],
      "sessionTimeout": 30,
      "phoneNumberId": "6891f1d0c45d123456789abc",
      "createdAt": "2026-07-21T13:45:18.000Z",
      "updatedAt": "2026-07-21T14:12:30.000Z"
```

</ResponseExample>

<ResponseField name="data" type="array[object]">
Your WhatsApp agents. When you have none, the message is `No whatsapp agent found` and `data` is empty.
</ResponseField>

<ResponseField name="data[]._id" type="string">
Agent ID.
</ResponseField>

<ResponseField name="data[].agentName" type="string">
Agent name.
</ResponseField>

<ResponseField name="data[].phoneNumberId" type="string | null">
ID of the WhatsApp integration the agent is attached to, if any.
</ResponseField>

<ResponseField name="data[].sessionTimeout" type="integer">
Minutes of user inactivity after which a conversation ends.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
