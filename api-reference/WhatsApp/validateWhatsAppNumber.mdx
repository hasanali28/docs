## Overview

Check with AiSensy that the token is valid and that the WhatsApp number is connected in that AiSensy account. Nothing is saved; connect the number afterwards with [Create WhatsApp Integration](/api-reference/WhatsApp/createWhatsAppIntegration), sending the same fields.

## Prerequisites

- An API key for your workspace
- An AiSensy account with the WhatsApp number connected, and its API token

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/validate-whatsapp-number' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "phoneNumber": "+15551234567",
    "token": "YOUR_AISENSY_API_TOKEN"
  }'
```

</RequestExample>

### Request Parameters

<ParamField body="phoneNumber" type="string" required>
The WhatsApp Business number, with country code.
</ParamField>

<ParamField body="token" type="string" required>
  Your AiSensy API token.
</ParamField>

<ParamField body="plan" default="basic" type="string">
  `basic` or `pro`.
</ParamField>

<ParamField body="projectId" type="string">
  Your AiSensy project ID. Required when `plan` is `pro`.
</ParamField>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "WhatsApp number and authentication token verified successfully!",
  "errorMessage": null,
  "data": {
    "verified": true
  }
}
```

</ResponseExample>

<ResponseField name="data.verified" type="boolean">
`true` when the number and token were verified. A failed check returns an error instead.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request**
  - `phoneNumber` or `token` is missing, or `projectId` is missing for `pro`.
  - `Invalid phone number format`.
  - `Number not found, not connected, or not verified.` – the number isn't connected in that AiSensy account.
  - AiSensy rejected the token.
- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
