## Overview

Set the webhook of your AiSensy account to Weya's WhatsApp webhook address, so incoming WhatsApp messages and events reach Weya. You can't choose the address: it is always Weya's.

Assigning an agent with [Assign Agent to WhatsApp Number](/api-reference/WhatsApp/assignAgentToWhatsAppNumber) already sets the webhook up, so you only need this endpoint to repair it.

## Prerequisites

- An API key for your workspace
- Your AiSensy API token

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField body="token" type="string" required>
Your AiSensy API token.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/update-whatsapp-webhook' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "token": "YOUR_AISENSY_API_TOKEN"
  }'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Webhook updated successfully!",
  "errorMessage": null,
  "data": {}
}
```

</ResponseExample>

<ResponseField name="data" type="object">
The response from AiSensy to the update.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `token is required`, or AiSensy rejected the token.
- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error, or AiSensy couldn't be reached.
