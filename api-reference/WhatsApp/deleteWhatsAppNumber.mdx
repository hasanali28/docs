---
title: "Delete WhatsApp Number"
description: "Remove a connected WhatsApp number from your workspace."
api: "DELETE /api/whatsapp/delete-whatsapp-number/{phoneNumberId}"
---

## Overview

Permanently delete one of your WhatsApp integrations. For a `pro` integration, Weya also tries to remove its AiSensy subscription; if that fails, the integration is still deleted.

The API doesn't check whether a WhatsApp agent is assigned to the number.

<Warning>
  This can't be undone. To use the number again, connect it again with [Create WhatsApp Integration](/api-reference/WhatsApp/createWhatsAppIntegration); it gets a new ID.
</Warning>

## Prerequisites

- An API key for your workspace
- The integration ID (`_id` from [Get WhatsApp Numbers](/api-reference/WhatsApp/getWhatsAppNumbers)), connected by the user who owns the API key

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="phoneNumberId" type="string" required>
Integration ID (the `_id` from Get WhatsApp Numbers).
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/whatsapp/delete-whatsapp-number/6891f1d0c45d123456789abc' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Whatsapp number deleted successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Phone Number ID`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `WhatsApp number not found`: it doesn't exist, is already deleted, or wasn't connected by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
