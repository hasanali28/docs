## Overview

List the WhatsApp templates saved in Weya for the user who owns the API key, for example the start templates of your WhatsApp agents. These are templates stored in Weya, not a live list from AiSensy: for that, use [Get WhatsApp Templates](/api-reference/WhatsApp/getTemplates).

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/get-all-templates' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

A successful request returns `status: true`, the message `Whatsapp templates fetched successfully`, and the saved templates in `data`. Each has a `templateName`, `templateVariables`, `templateId` and `templateLanguage`. When you have none, the message is `No whatsapp template found` and `data` is empty.

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
