---

## Overview

Update the phone number or AiSensy token of one of your WhatsApp integrations. Send only the fields you want to change. The new values are saved as sent and aren't checked with AiSensy, so check them first with [Validate WhatsApp Number](/api-reference/WhatsApp/validateWhatsAppNumber).

## Prerequisites

- An API key for your workspace
- The integration ID (`_id` from [Get WhatsApp Numbers](/api-reference/WhatsApp/getWhatsAppNumbers)), connected by the user who owns the API key

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="phoneNumberId" type="string" required>
Integration ID (the `_id` from Get WhatsApp Numbers), not the phone number itself.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/whatsapp/update-integration/6891f1d0c45d123456789abc' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "token": "NEW_AISENSY_API_TOKEN"
  }'
```

</RequestExample>

### Request Parameters

<ParamField body="token" type="string">
New AiSensy API token.
</ParamField>

<ParamField body="phoneNumber" type="string">
New WhatsApp number. Must not already be connected in another integration.
</ParamField>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Whatsapp integration updated successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

<ResponseField name="message" type="string">
`Whatsapp integration updated successfully`. The updated integration isn't returned; use Get WhatsApp Numbers to see it.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Phone Number ID`, an empty `token` or `phoneNumber`, or `WhatsApp integration already exists for this phone number`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `WhatsApp integration not found`: it doesn't exist or wasn't connected by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
