---

## Overview

Retrieve a WhatsApp agent's full configuration, including its start template and the voice name. The agent must have been created by the user who owns the API key.

## Prerequisites

- An API key for your workspace
- The agent's ID, from [Get WhatsApp Agents](/api-reference/WhatsApp/getWhatsAppAgents)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="agentId" type="string" required>
ID of the WhatsApp agent.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/get-whatsapp-agent/6894a98a7fcde123456789ab' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data" type="object">
The agent's configuration: name, gender, voice, instructions (`systemMessage`), languages, analysis metrics, tools, templates, knowledge base (`rag`), variables, `sessionTimeout` and `settings`. The example shows the main fields.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Agent ID`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `WhatsApp agent not found`: it doesn't exist or wasn't created by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
