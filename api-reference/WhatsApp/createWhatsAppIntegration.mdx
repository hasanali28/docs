## Overview

Connect a WhatsApp Business number to Weya, for the user who owns the API key. WhatsApp numbers are connected through AiSensy, using your AiSensy API token.

There are two plans:

- **`basic`** (default) – the number and token are saved as sent. Check them first with [Validate WhatsApp Number](/api-reference/WhatsApp/validateWhatsAppNumber).
- **`pro`** – also needs your AiSensy `projectId`. The credentials are checked with AiSensy and Weya subscribes to the project's message events before the number is saved.

The response's `_id` is the ID that the other WhatsApp endpoints call `phoneNumberId`.

## Prerequisites

- An API key for your workspace
- An AiSensy account with the WhatsApp number connected, and its API token

## Request

<ParamField header="x-api-key" type="string" required>
  Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/whatsapp/whatsapp-integration' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "provider": "AI_SENSY",
    "plan": "basic",
    "phoneNumber": "+15551234567",
    "token": "YOUR_AISENSY_API_TOKEN"
  }'
```

</RequestExample>

### Request Parameters

<ParamField body="provider" type="string" required>
  Always `AI_SENSY`.
</ParamField>

<ParamField body="phoneNumber" type="string" required>
  The WhatsApp Business number, with country code.
</ParamField>

<ParamField body="token" type="string" required>
  Your AiSensy API token.
</ParamField>

<ParamField body="plan" default="basic" type="string">
  `basic` or `pro`.
</ParamField>

<ParamField body="projectId" type="string">
  Your AiSensy project ID. Required when `plan` is `pro`.
</ParamField>

<ResponseField name="data._id" type="string">
  Integration ID. Use it as `phoneNumberId` in the other WhatsApp endpoints.
</ResponseField>

<ResponseField name="data.plan" type="string">
  `basic` or `pro`.
</ResponseField>

<ResponseField name="data.token" type="string">
  The AiSensy token you sent, in plain text. Don't log the response.
</ResponseField>

<ResponseField name="data.webhookStatus" type="string">
  `pro` only: `configured` when Weya is subscribed to the project's events.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request**
  - `provider` isn't `AI_SENSY`, `phoneNumber` or `token` is missing, or `projectId` is missing for `pro`.
  - `WhatsApp integration already exists for this phone number`.
  - `pro`: `WhatsApp integration already exists for this AiSensy project`, or AiSensy rejected the credentials.
- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
