---
title: "Remove Agent from WhatsApp Number"
description: "Unassign the WhatsApp agent from a connected number."
api: "PUT /api/whatsapp/remove-agent-in-whatsapp-number/{phoneNumberId}"
---

## Overview

Remove the agent assigned to one of your WhatsApp integrations. The agent itself isn't deleted, and the integration stays connected. The number has no agent until you assign one with [Assign Agent to WhatsApp Number](/api-reference/WhatsApp/assignAgentToWhatsAppNumber).

## Prerequisites

- An API key for your workspace
- The integration ID (`_id` from [Get WhatsApp Numbers](/api-reference/WhatsApp/getWhatsAppNumbers))

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="phoneNumberId" type="string" required>
Integration ID (the `_id` from Get WhatsApp Numbers).
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/whatsapp/remove-agent-in-whatsapp-number/6891f1d0c45d123456789abc' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Whatsapp number unlinked successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

The request also succeeds when the number has no agent.

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Phone Number ID`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `WhatsApp number not found`: it doesn't exist or wasn't connected by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 WhatsApp requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
