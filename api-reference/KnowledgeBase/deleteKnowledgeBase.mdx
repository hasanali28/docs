## Overview

Permanently delete one of your organization's knowledge bases, with all its files and its search index.

The knowledge base is not removed from agents that use it. Remove it from those agents with [Update Agent](/api-reference/Agents/updateAgent) (`knowledgeBase`) so they don't refer to a deleted knowledge base.

<Warning>
  This can't be undone.
</Warning>

## Prerequisites

- An API key for your workspace
- The knowledge base ID, from [Get Knowledge Bases](/api-reference/KnowledgeBase/getKnowledgeBases)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="knowledgeBaseId" type="string" required>
ID of the knowledge base to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/knowledgeBase/687b1c2ab7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

A successful request returns `204 No Content` with no body.

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `knowledgeBaseId` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `KnowledgeBase not found`: it doesn't exist in your organization.
- **429 Too Many Requests** – More than 1,000 Knowledge Base requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
- **502 Bad Gateway** – `Failed to delete vector storage. Knowledge base deletion aborted: …`. The files may already be deleted; send the request again.
