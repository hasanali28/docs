---
title: "List Knowledge Base Documents"
description: "List the files stored in a knowledge base."
api: "GET /api/knowledgeBase/{knowledgeBaseId}/documents"
---

## Overview

List the files stored in one of your organization's knowledge bases, with their size and last-modified time.

## Prerequisites

- An API key for your workspace
- The knowledge base ID, from [Get Knowledge Bases](/api-reference/KnowledgeBase/getKnowledgeBases)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="knowledgeBaseId" type="string" required>
ID of the knowledge base.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/knowledgeBase/687b1c2ab7c7d3f123456789/documents' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Documents listed successfully",
  "errorMessage": null,
  "data": [
    {
      "fileName": "FAQ.pdf",
      "size": 245760,
      "lastModified": "2026-07-20T10:30:00.000Z"
    },
    {
      "fileName": "Pricing.docx",
      "size": 185430,
      "lastModified": "2026-07-20T10:35:00.000Z"
    }
  ]
}
```

</ResponseExample>

<ResponseField name="data" type="array[object]">
The files in the knowledge base.
</ResponseField>

<ResponseField name="data[].fileName" type="string">
File name.
</ResponseField>

<ResponseField name="data[].size" type="integer">
File size in bytes.
</ResponseField>

<ResponseField name="data[].lastModified" type="string">
When the file was last uploaded (ISO 8601).
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `knowledgeBaseId` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `KnowledgeBase not found`: it doesn't exist in your organization.
- **429 Too Many Requests** – More than 1,000 Knowledge Base requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
