---
title: "Get Knowledge Bases"
description: "Retrieve all Knowledge Bases available in your workspace."
api: "GET /api/knowledgeBase"
---

## Overview

Retrieve a paginated list of all Knowledge Bases available in your workspace. This endpoint supports pagination and search, making it easy to browse or locate specific Knowledge Bases.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="page" type="integer">
Page number to retrieve. Defaults to the first page if omitted.
</ParamField>

<ParamField query="pageSize" type="integer">
Number of knowledge bases per page.
</ParamField>

<ParamField query="searchKb" type="string">
Only return knowledge bases whose name contains this text.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/knowledgeBase?page=1&pageSize=10&searchKb=sales' \
--header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Knowledge Bases fetched successfully",
  "errorMessage": "",
  "data": {
    "knowledgeBases": [
      {
        "_id": "687b1c2ab7c7d3f123456789",
        "knowledgeBaseName": "Sales Knowledge Base",
        "description": "Contains sales documents and FAQs.",
        "status": "PROCESSED",
        "vectorDbCollection": "kb_687b1c2ab7c7d3f123456789",
        "createdAt": "2026-07-20T10:00:00.000Z"
      }
    ],
    "pagination": {
      "total": 1,
      "currentPage": 1,
      "pageSize": 10
    }
  }
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the request completed successfully.
</ResponseField>

<ResponseField name="code" type="integer" required>
HTTP status code returned by the API.
</ResponseField>

<ResponseField name="message" type="string" required>
Human-readable success message.
</ResponseField>

<ResponseField name="data.knowledgeBases" type="array[object]" required>
The knowledge bases on this page.
</ResponseField>

<ResponseField name="data.knowledgeBases[]._id" type="string">
Knowledge base ID.
</ResponseField>

<ResponseField name="data.knowledgeBases[].knowledgeBaseName" type="string">
Name of the knowledge base.
</ResponseField>

<ResponseField name="data.knowledgeBases[].description" type="string">
Description of the knowledge base.
</ResponseField>

<ResponseField name="data.knowledgeBases[].status" type="string">
Processing status of the uploaded documents: `PENDING`, `PROCESSING`, `PROCESSED` or `FAILED`.
</ResponseField>

<ResponseField name="data.knowledgeBases[].vectorDbCollection" type="string">
Collection name. Use it as `rag.vectorDBCollection` to connect the knowledge base to a video agent.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `currentPage` and `pageSize`.
</ResponseField>

## Response Codes

| Code | Description |
|------|-------------|
| 200 | Knowledge Bases fetched successfully |
| 401 | Unauthorized |
| 500 | Internal Server Error |

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error while retrieving Knowledge Bases.

<Note>

Use the **search** parameter to quickly locate a specific Knowledge Base by its name.

</Note>

<Check>

The returned **Knowledge Base ID** can be used with:

- `GET /api/knowledgeBase/{knowledgeBaseId}`
- `PUT /api/knowledgeBase/{knowledgeBaseId}`
- `DELETE /api/knowledgeBase/{knowledgeBaseId}`
- `GET /api/knowledgeBase/{knowledgeBaseId}/documents`

</Check>
