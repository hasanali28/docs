title: "Get Knowledge Bases"

---

## Overview

List the knowledge bases in your organization, newest first, with pagination and search.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="page" default="1" type="integer">
Page number.
</ParamField>

<ParamField query="limit" default="10" type="integer">
Number of knowledge bases per page, up to 100.
</ParamField>

<ParamField query="search" type="string">
Case-insensitive text matched against the name, description and status. Partial matches are returned.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/knowledgeBase?page=1&limit=10&search=sales' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Fetched successfully",
  "errorMessage": null,
  "data": {
    "knowledgeBases": [
      {
        "_id": "687b1c2ab7c7d3f123456789",
        "knowledgeBaseName": "Sales Knowledge Base",
        "description": "Contains sales documents and FAQs.",
        "status": "PENDING",
        "vectorDbCollection": "kb_sales_1a2b3c",
        "createdAt": "2026-07-20T10:00:00.000Z"
      }
    ],
    "pagination": {
      "total": 1,
      "page": 1,
      "limit": 10,
      "totalPages": 1,
      "hasNextPage": false,
      "hasPrevPage": false
    }
  }
}
```

</ResponseExample>

<ResponseField name="data.knowledgeBases" type="array[object]" required>
The knowledge bases on this page.
</ResponseField>

<ResponseField name="data.knowledgeBases[]._id" type="string">
Knowledge base ID. Use it in an agent's `knowledgeBase`.
</ResponseField>

<ResponseField name="data.knowledgeBases[].knowledgeBaseName" type="string">
Name of the knowledge base.
</ResponseField>

<ResponseField name="data.knowledgeBases[].description" type="string">
Description of the knowledge base.
</ResponseField>

<ResponseField name="data.knowledgeBases[].status" type="string">
Always `PENDING`; it isn't updated after creation. A knowledge base with a `vectorDbCollection` has been indexed.
</ResponseField>

<ResponseField name="data.knowledgeBases[].vectorDbCollection" type="string">
Name of the search index. A video agent uses it as `rag.vectorDBCollection`. Empty if indexing failed.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `No KnowledgeBases found`: no knowledge base matches, including when your organization has none or the page is past the end.
- **429 Too Many Requests** – More than 1,000 Knowledge Base requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
