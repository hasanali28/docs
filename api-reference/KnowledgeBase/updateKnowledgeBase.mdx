title: "Update Knowledge Base"
description: "Rename a knowledge base, change its description, or store more files in it."
api: "PUT /api/knowledgeBase/{knowledgeBaseId}"
---

## Overview

Update one of your organization's knowledge bases. Send only the fields you want to change. Existing files are kept.

<Warning>
  Files uploaded with this endpoint are stored but the knowledge base is **not indexed again**, so agents can't answer from them yet. To add files that agents can use, upload them with [Create Knowledge Base](/api-reference/KnowledgeBase/createKnowledgeBase) using the same `knowledgeBaseName`; that indexes the whole knowledge base again.
</Warning>

## Prerequisites

- An API key for your workspace
- The knowledge base ID, from [Get Knowledge Bases](/api-reference/KnowledgeBase/getKnowledgeBases)
- Send the request as `multipart/form-data`

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="knowledgeBaseId" type="string" required>
ID of the knowledge base.
</ParamField>

<ParamField body="knowledgeBaseName" type="string">
New name. An empty value is ignored.
</ParamField>

<ParamField body="description" type="string">
New description.
</ParamField>

<ParamField body="files" type="file[]">
Files to store: up to 50 files of up to 10 MB each. A file with the same name as an existing one replaces it.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/knowledgeBase/687b1c2ab7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY' \
  --form 'knowledgeBaseName="Updated Customer Support KB"' \
  --form 'description="Updated support documentation"'
```

</RequestExample>

<ResponseField name="data" type="object">
The updated knowledge base record. It doesn't list files; use [List Knowledge Base Documents](/api-reference/KnowledgeBase/listKnowledgeBaseDocuments).
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `knowledgeBaseId` isn't a valid ID, `File exceeds the 10MB per-file limit`, or `You can upload at most 50 files per request`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `KnowledgeBase not found`: it doesn't exist in your organization.
- **429 Too Many Requests** – More than 1,000 Knowledge Base requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
