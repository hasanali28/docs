---
title: "Get Knowledge Base By ID"
description: "Retrieve the details of one knowledge base in your organization."
api: "GET /api/knowledgeBase/{knowledgeBaseId}"
---

## Overview

Retrieve one knowledge base in your organization. The response has its name, description and search index, but not its files: list those with [List Knowledge Base Documents](/api-reference/KnowledgeBase/listKnowledgeBaseDocuments).

## Prerequisites

- An API key for your workspace
- The knowledge base ID, from [Get Knowledge Bases](/api-reference/KnowledgeBase/getKnowledgeBases)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="knowledgeBaseId" type="string" required>
ID of the knowledge base.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/knowledgeBase/687b1c2ab7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

    "description": "Contains FAQs and support documentation.",

<ResponseField name="data._id" type="string">
Knowledge base ID.
</ResponseField>

<ResponseField name="data.knowledgeBaseName" type="string">
Name of the knowledge base.
</ResponseField>

<ResponseField name="data.description" type="string">
Description of the knowledge base.
</ResponseField>

<ResponseField name="data.vectorDbCollection" type="string">
Name of the search index. A video agent uses it as `rag.vectorDBCollection`.
</ResponseField>

<ResponseField name="data.status" type="string">
Always `PENDING`; it isn't updated after creation.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `knowledgeBaseId` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `KnowledgeBase not found`: it doesn't exist in your organization.
- **429 Too Many Requests** – More than 1,000 Knowledge Base requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
