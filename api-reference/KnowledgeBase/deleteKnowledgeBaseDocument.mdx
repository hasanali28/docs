<Danger>
  **Known issue: don't use this endpoint for now.** It currently deletes the **entire knowledge base**, with all its files and its search index, instead of the one file named in the path. It behaves exactly like [Delete Knowledge Base](/api-reference/KnowledgeBase/deleteKnowledgeBase) and returns `204 No Content`. This page will be updated when it is fixed.
</Danger>

## Overview

Intended to delete one file from one of your organization's knowledge bases, keeping the other files.

## Prerequisites

- An API key for your workspace
- The knowledge base ID, and the file name from [List Knowledge Base Documents](/api-reference/KnowledgeBase/listKnowledgeBaseDocuments)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="knowledgeBaseId" type="string" required>
ID of the knowledge base.
</ParamField>

<ParamField path="fileName" type="string" required>
Name of the file, URL-encoded.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/knowledgeBase/687b1c2ab7c7d3f123456789/documents/FAQ.pdf' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

A successful request returns `204 No Content` with no body.

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `knowledgeBaseId` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `KnowledgeBase not found`: it doesn't exist in your organization.
- **429 Too Many Requests** – More than 1,000 Knowledge Base requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
