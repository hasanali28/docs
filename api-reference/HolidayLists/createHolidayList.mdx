---

## Overview

Create a holiday list. Campaigns that use it don't place calls on its dates. To start from a country's public holidays, fetch them with **Get Template Holidays** and send them as `holidays`.

## Prerequisites

- An API key for your workspace
- Holiday lists are turned on for your organization (see **Toggle Holiday Lists**)

## Endpoint

<ParamField method="POST" path="/api/holiday-list" />

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/holiday-list' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "India Holidays",
    "isDefault": true,
    "holidays": [
      { "label": "Republic Day", "date": "2026-01-26" },
      { "label": "Independence Day", "date": "2026-08-15" }
    ]
}'
```

</RequestExample>

### Request Parameters

<ParamField body="name" type="string" required>
Name of the holiday list.
</ParamField>

<ParamField body="holidays" type="array[object]" required>
The holidays. Each item has:

- `label` – name of the holiday
- `date` – the date, in `YYYY-MM-DD` format
</ParamField>

<ParamField body="isDefault" type="boolean">
Set to `true` to make this the default list, preselected when creating a campaign in the dashboard.
</ParamField>

<ResponseField name="data" type="object" required>
The new holiday list. `data._id` is the ID to use as `holidayListId` on a campaign.
</ResponseField>

## Error Handling

- **400 Bad Request** – Missing `name` or `holidays`, or a date that isn't in `YYYY-MM-DD` format.
- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.
