---
title: "Toggle Holiday Lists"
description: "Turn holiday lists on or off for your whole organization."
api: "PATCH /api/holiday-list/toggle"
---

## Overview

Turn the holiday list feature on or off for your organization. This is an organization-wide setting, not a setting for one list. When it's off, the **Holiday List** option is hidden when creating or editing a campaign.

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField method="PATCH" path="/api/holiday-list/toggle" />

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PATCH 'https://api.weya.live/backend/api/holiday-list/toggle' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "enable": true
}'
```

</RequestExample>

### Request Parameters

<ParamField body="enable" type="boolean" required>
`true` to turn holiday lists on, `false` to turn them off.
</ParamField>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "",
  "errorMessage": "",
  "data": null
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the setting was changed.
</ResponseField>

## Error Handling

- **400 Bad Request** – `enable` is missing or isn't a boolean.
- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.
