---
title: "Get Holiday Lists"
description: "Retrieve all holiday lists in your organization."
api: "GET /api/holiday-list"
---

## Overview

List the holiday lists in your organization, including lists created by other users in it. A campaign that uses a holiday list does not place calls on the dates in it.

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField path="/api/holiday-list" method="GET">
</ParamField>

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/holiday-list' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data" type="array[object]" required>
The holiday lists in your organization.
</ResponseField>

<ResponseField name="data[]._id" type="string">
Holiday list ID. Use it as `holidayListId` on a campaign.
</ResponseField>

<ResponseField name="data[].name" type="string">
Name of the holiday list.
</ResponseField>

<ResponseField name="data[].isDefault" type="boolean">
Whether this is the organization's default list. There is at most one. The default list is preselected when you create a campaign in the dashboard.
</ResponseField>

<ResponseField name="data[].holidays" type="array[object]">
The holidays, each with a `label` and a `date` (`YYYY-MM-DD`).
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.
