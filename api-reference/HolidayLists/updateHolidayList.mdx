---

## Overview

Update a holiday list. Send only the fields you want to change. If you send `holidays`, it replaces the whole list of dates.

## Prerequisites

- An API key for your workspace
- The holiday list's ID (`_id` from [Get Holiday Lists](/api-reference/HolidayLists/getHolidayLists)), in your organization

## Endpoint

<ParamField path="/api/holiday-list/{id}" method="PUT">
</ParamField>

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the holiday list to update.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/holiday-list/68a1f2c3b7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "India Holidays 2026",
    "holidays": [
      { "label": "Republic Day", "date": "2026-01-26" },
      { "label": "Independence Day", "date": "2026-08-15" },
      { "label": "Gandhi Jayanti", "date": "2026-10-02" }
    ]
}'
```

</RequestExample>

### Request Parameters

<ParamField body="name" type="string">
New name for the holiday list. Can't be empty.
</ParamField>

<ParamField body="holidays" type="array[object]">
The full list of holidays, replacing the current one. Each item has a `label` and a `date` in `YYYY-MM-DD` format.
</ParamField>

<ParamField body="isDefault" type="boolean">
Set to `true` to make this the organization's default list; the previous default stops being the default. `false` is ignored: to change the default, set another list to `true`.
</ParamField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Holiday list name cannot be empty`, `Holidays must be an array`, `Each holiday must have a valid date and label`, or `Each holiday must have a valid date format`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Holiday list not found`: the list doesn't exist in your organization.
- **500 Internal Server Error** – Unexpected server error.
