---

## Overview

Get the public holidays for a country, ready to send as `holidays` to [Create Holiday List](/api-reference/HolidayLists/createHolidayList). Nothing is saved by this call.

The templates contain 2026 dates only. For other years, edit the dates before saving them.

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField path="/api/holiday-list/templates/{region}" method="GET">
</ParamField>

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="region" type="string" required>
Country code: `IN` (India), `US` (United States), `AU` (Australia) or `AE` (GCC / UAE). Not case-sensitive.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/holiday-list/templates/IN' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Template holidays fetched successfully",
  "errorMessage": null,
  "data": [
    { "label": "Republic Day", "date": "2026-01-26" },
    { "label": "Independence Day", "date": "2026-08-15" },
    { "label": "Mahatma Gandhi Jayanti", "date": "2026-10-02" }
  ]
}
```

</ResponseExample>

<ResponseField name="data" type="array[object]" required>
The holidays, each with a `label` and a `date` in `YYYY-MM-DD` format.
</ResponseField>

## Error Handling

- **400 Bad Request** – `Unsupported region: …. Supported regions: IN, US, AU, AE`.
- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Check>

Send the returned list as `holidays` to `POST /api/holiday-list` to save it as a holiday list.

</Check>
