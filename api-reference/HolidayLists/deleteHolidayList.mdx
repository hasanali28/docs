## Overview

Delete a holiday list from your organization. The default list can't be deleted: make another list the default first with [Update Holiday List](/api-reference/HolidayLists/updateHolidayList).

The API doesn't check whether campaigns use the list. Remove it from those campaigns first with [Update Campaign](/api-reference/Campaigns/updateBatch) (`holidayListId: ""`).

## Prerequisites

- An API key for your workspace
- The holiday list's ID (`_id` from [Get Holiday Lists](/api-reference/HolidayLists/getHolidayLists))

## Endpoint

<ParamField path="/api/holiday-list/{id}" method="DELETE">
</ParamField>

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the holiday list to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/holiday-list/68a1f2c3b7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Holiday list deleted successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the holiday list was deleted.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Cannot delete the default holiday list`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Holiday list not found`: the list doesn't exist in your organization.
- **500 Internal Server Error** – Unexpected server error.
