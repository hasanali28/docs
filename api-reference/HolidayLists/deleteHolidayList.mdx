---
title: "Delete Holiday List"
description: "Delete a holiday list from your organization."
api: "DELETE /api/holiday-list/{id}"
---

## Overview

Delete a holiday list. Campaigns that used it no longer skip its dates.

## Prerequisites

- An API key for your workspace
- The holiday list's ID

## Endpoint

<ParamField method="DELETE" path="/api/holiday-list/{id}" />

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the holiday list to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/holiday-list/68a1f2c3b7c7d3f123456789' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "",
  "errorMessage": "",
  "data": null
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the holiday list was deleted.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – The holiday list does not exist in your organization.
- **500 Internal Server Error** – Unexpected server error.
