## Overview

Retrieve the phone numbers associated with a specific user by providing the user's unique User ID.

## Prerequisites

- Bearer token for an authenticated workspace
- Valid User ID

<Tip>

You can retrieve the **User ID** from the Weya AI Dashboard or from the relevant user information available in your workspace.

</Tip>

## Path Parameters

<ParamField path="userId" type="string" required>
Unique identifier of the user whose phone numbers you want to retrieve.
</ParamField>

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/call/get-phone/{userId}' \
--header 'Authorization: Bearer {{authToken}}'
````

</RequestExample>

## Response Codes

| Code | Description                          |
| ---- | ------------------------------------ |
| 200  | Phone numbers retrieved successfully |
| 400  | Invalid User ID                      |
| 401  | Unauthorized                         |
| 403  | Forbidden                            |
| 404  | User or phone numbers not found      |
| 500  | Internal Server Error                |

## Error Handling

* **400 Bad Request** – Invalid or missing User ID.
* **401 Unauthorized** – Missing or invalid Bearer token.
* **403 Forbidden** – You do not have permission to access these phone numbers.
* **404 Not Found** – User or phone numbers could not be found.
* **500 Internal Server Error** – Unexpected server error.

<Note>

The endpoint returns an array containing the phone number records associated with the specified user.

</Note>
