api: "GET /api/calls/{id}"
---

## Overview

Retrieve the complete details of a specific call. This endpoint returns information such as the phone number, call status, call duration, recording details, transcription, and call analysis generated after the conversation.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to access Calls
- A valid Call ID

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField path="id" type="string" required>
Unique identifier of the call.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/calls/6895d6a7d3f7a12345678901' \
--header 'Authorization: Bearer {{authToken}}'
```

</RequestExample>

## Error Handling

- **400 Bad Request** – Invalid Call ID.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to access this call.
- **404 Not Found** – Call not found.
- **500 Internal Server Error** – Unexpected server error.

<Note>

This endpoint returns the complete details of a single call, including its call logs, recording information, transcription, and post-call analysis if available.

</Note>
