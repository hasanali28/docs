---

## Overview

Retrieve the audio recording associated with a specific call. Use this endpoint to access call recordings for quality assurance, auditing, compliance, or review purposes.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to access Calls
- A valid Call ID
- The call must have a recording available

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField path="id" type="string" required>
Unique identifier of the call.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/calls/1234d6a7d3f7a12345678901/recording' \
--header 'Authorization: Bearer {{authToken}}'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Call recording retrieved successfully",
  "data": {
    "callId": "1234d6a7d3f7a12345678901",
    "recordingId": "rec_123456789",
    "recordingUrl": "https://storage.example.com/recordings/rec_123456789.mp3",
    "duration": 141,
    "createdAt": "2025-07-20T10:30:00.000Z"
  }
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the request completed successfully.
</ResponseField>

<ResponseField name="code" type="integer" required>
HTTP status code.
</ResponseField>

<ResponseField name="message" type="string" required>
Human-readable success message.
</ResponseField>

<ResponseField name="data.callId" type="string">
Unique identifier of the call.
</ResponseField>

<ResponseField name="data.recordingId" type="string">
Unique identifier of the recording.
</ResponseField>

<ResponseField name="data.recordingUrl" type="string">
URL of the call recording.
</ResponseField>

<ResponseField name="data.duration" type="number">
Duration of the recording in seconds.
</ResponseField>

<ResponseField name="data.createdAt" type="string">
Timestamp when the recording was created.
</ResponseField>

## Error Handling

- **400 Bad Request** – Invalid Call ID.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to access this recording.
- **404 Not Found** – Call or recording not found.
- **500 Internal Server Error** – Unexpected server error.

<Note>

This endpoint returns the recording associated with a call. If recording is disabled or unavailable for the specified call, the API returns a **404 Not Found** response.

</Note>
