## Overview

Create a new campaign to organize and manage outbound AI calling. A campaign defines the campaign name, assigned agent, phone number, calling schedule, retry settings, and other call configurations.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to create campaigns
- An existing AI Agent
- A configured Phone Number

## Endpoint

<ParamField method="POST" path="/api/campaigns" />

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/campaigns' \
  --header 'Authorization: Bearer {{authToken}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "campaignName": "Sales Campaign",
    "agentId": "687b1c2ab7c7d3f123456789",
    "phoneNumberId": "6889c4ab7c7d3f987654321",
    "timezone": "Asia/Kolkata",
    "retry": 2,
    "delay": 30
}'
```

</RequestExample>

### Request Parameters

<ParamField body="campaignName" type="string" required>

</ParamField>

<ParamField body="agentId" type="string" required>

</ParamField>

<ParamField body="phoneNumberId" type="string" required>

</ParamField>

</ParamField>

Number of retry attempts for unanswered or failed calls.
</ParamField>

<ParamField body="delay" type="integer">
Delay in seconds between retry attempts.
</ParamField>

## Error Handling

- **400 Bad Request** – Invalid request body or missing required fields.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to create campaigns.
- **409 Conflict** – A campaign with the same name already exists.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Creating a campaign only creates the campaign configuration. Calls will not begin until the campaign is started using the **Start Campaign** endpoint.

</Note>

<Check>

After creating a campaign, you can:

- `GET /api/campaigns` to list all campaigns.
- `GET /api/campaigns/{id}` to retrieve campaign details.
- `PATCH /api/campaigns/{id}` to update the campaign.
- `POST /api/campaigns/{id}/start` to start the campaign.
- `POST /api/campaigns/{id}/stop` to stop the campaign.

</Check>
