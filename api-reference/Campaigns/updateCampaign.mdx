---
title: "Update Campaign"
description: "Update an existing campaign using its unique ID."
api: "PATCH /api/campaigns/{id}"
---

## Overview

Update the configuration of an existing campaign. You can modify campaign settings such as the campaign name, calling schedule, retry configuration, timezone, allowed calling days, or other supported campaign properties.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to manage Campaigns
- A valid Campaign ID

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField path="id" type="string" required>
Unique identifier of the campaign to update.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PATCH '{{baseUrl}}/api/campaigns/{id}' \
--header 'Authorization: Bearer {{authToken}}' \
--header 'Content-Type: application/json' \
--data '{
  "campaignName": "Updated Sales Campaign",
  "retry": 2,
  "delay": 60,
  "timezone": "Asia/Kolkata",
  "allowedDays": [
    "Monday",
    "Tuesday",
    "Wednesday",
    "Thursday",
    "Friday"
  ]
}'
```

</RequestExample>

### Request Body

| Field | Type | Description |
|--------|------|-------------|
| `campaignName` | string | Updated name of the campaign. |
| `retry` | integer | Number of retry attempts for failed calls. |
| `delay` | integer | Delay (in seconds) before retrying a failed call. |
| `timezone` | string | Timezone used while scheduling calls. |
| `allowedDays` | array | Days on which the campaign is allowed to make calls. |

## Error Handling

- **400 Bad Request** – Invalid request body or campaign ID.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to update campaigns.
- **404 Not Found** – Campaign not found.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Only include the fields you want to update. Fields omitted from the request remain unchanged.

</Note>
