---
title: "Get Campaign by ID"
description: "Retrieve the details of a specific campaign using its unique ID."
api: "GET /api/campaigns/{id}"
---

## Overview

Retrieve the complete details of a specific campaign by providing its unique Campaign ID.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to access Campaigns

## Endpoint

<ParamField method="GET" path="/api/campaigns/{id}" />

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField path="id" type="string" required>
The unique identifier of the campaign.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/campaigns/6895d6a7d3f7a12345678901' \
  --header 'Authorization: Bearer {{authToken}}'
```

</RequestExample>

## Error Handling

- **400 Bad Request** – Invalid campaign ID.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to access this campaign.
- **404 Not Found** – Campaign not found.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Provide a valid **Campaign ID** to retrieve the campaign details. If the campaign does not exist, the API returns a **404 Not Found** response.

</Note>

<Check>

Use the returned **Campaign ID** with:

- `PATCH /api/campaigns/{id}` to update the campaign.
- `DELETE /api/campaigns/{id}` to delete the campaign.
- `POST /api/campaigns/{id}/start` to start the campaign.
- `POST /api/campaigns/{id}/stop` to stop the campaign.

</Check>
