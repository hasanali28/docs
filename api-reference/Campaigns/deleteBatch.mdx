---
title: "Delete Campaign"
description: "Delete a campaign. This stops it and removes it from your campaign list."
api: "DELETE /api/call/delete-batch/{batchId}"
---

## Overview
Delete a campaign you no longer need. Deleting stops the campaign and hides it from your campaign list. It cannot be undone, but the record is kept: you can still retrieve it with `GET /api/call/batches/{userId}?includeDeleted=true`.

## Prerequisites
- An API key for your workspace
- Confirm no audits or dispute processes require the campaign history.

## Request
<ParamField path="batchId" type="string" required>
Identifier of the campaign to delete.
</ParamField>

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>
```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/call/delete-batch/6880bac05860c9b91c53c790' \
  --header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

## Response
<ResponseExample>
```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Batch deleted successfully",
  "errorMessage": "",
  "data": null
}
```
</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the campaign was deleted.
</ResponseField>

<ResponseField name="message" type="string" required>
Human-readable confirmation message.
</ResponseField>

## Error Handling
- **400 Bad Request** – Invalid `batchId` supplied.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – Campaign already deleted or does not belong to the workspace.
- **500 Internal Server Error** – Deletion failed; retry, then escalate with the campaign id.

<Warning>
This operation cannot be undone. Export call data first with `GET /api/call/export/csv?batchId={batchId}&format=csv&columns=[...]` if you need it.
</Warning>
