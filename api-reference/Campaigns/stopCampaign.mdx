---
title: "Stop Campaign"
description: "Stop a running campaign using its unique ID."
openapi: "POST /api/campaigns/{id}/stop"
---

## Overview

Stop a running campaign. Once stopped, the campaign immediately stops processing new calls. Any calls that have already been initiated may continue until they are completed.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to manage Campaigns
- A valid Campaign ID
- The campaign must be in a running state

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField path="id" type="string" required>
Unique identifier of the campaign to stop.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request POST '{{baseUrl}}/api/campaigns/{id}/stop' \
--header 'Authorization: Bearer {{authToken}}'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Campaign stopped successfully",
  "data": {
    "_id": "1234d6a7d3f7a12345678901",
    "status": "stopped",
    "stoppedAt": "2025-07-20T16:15:30.000Z"
  }
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the request completed successfully.
</ResponseField>

<ResponseField name="code" type="integer" required>
HTTP status code.
</ResponseField>

<ResponseField name="message" type="string" required>
Human-readable success message.
</ResponseField>

<ResponseField name="data" type="object" required>
Contains the updated campaign status.
</ResponseField>

<ResponseField name="data._id" type="string">
Unique identifier of the campaign.
</ResponseField>

<ResponseField name="data.status" type="string">
Current status of the campaign. After a successful request, the status is `stopped`.
</ResponseField>

<ResponseField name="data.stoppedAt" type="string">
Timestamp indicating when the campaign was stopped.
</ResponseField>

## Error Handling

- **400 Bad Request** – Campaign cannot be stopped in its current state.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to stop this campaign.
- **404 Not Found** – Campaign not found.
- **409 Conflict** – Campaign is already stopped or completed.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Stopping a campaign prevents any new calls from being initiated. Calls that are already in progress may continue until they finish.

</Note>
