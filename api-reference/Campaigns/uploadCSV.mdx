---
title: "Upload Campaign CSV"
description: "Create a campaign and populate it by uploading a CSV file of contacts."
api: "POST /api/call/upload"
---

## Overview
The CSV upload endpoint lets you bootstrap a campaign directly from a spreadsheet. Nexus validates the file, creates a campaign, normalises the columns based on the agent’s variable schema, and inserts the calls in a single transaction.

## Prerequisites
- An API key for your workspace
- CSV file containing the columns required by the agent.
- At least one provisioned phone number to associate with the campaign.

## Request
<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField formData="file" type="file" required>
CSV file to import. Use UTF-8 encoding and include headers.
</ParamField>

<ParamField formData="userId" type="string" required>
Workspace user who should own the campaign.
</ParamField>

<ParamField formData="batchName" type="string" required>
Display name for the new campaign.
</ParamField>

<ParamField formData="callingNumbers" type="string" required>
JSON stringified array of phone number IDs that the dialer will use when calling. Example: `"[\"64e5f12345abcdef87654321\"]"`.
</ParamField>

<ParamField formData="batchType" type="string" required allowedValues="outbound,mixed,inbound">
Type of campaign: `outbound` for outbound-only campaigns, `mixed` for outbound campaigns that also accept callbacks, or `inbound` for campaigns that only receive calls (no CSV needed).
</ParamField>

<ParamField formData="enableDNC" type="string">
Set to `"true"` to enable DNC checking for this campaign. Must match your organization's DNC setting.
</ParamField>

<ParamField formData="type" type="string">
Set to `"true"` to skip invalid rows and upload only the valid ones. Default is `"false"`, which rejects the upload if any row is invalid.
</ParamField>

<ParamField formData="mandatoryVariables" type="string">
JSON stringified array of variables every row must have a value for. Example: `"[\"customer_name\"]"`.
</ParamField>

<ParamField formData="retry" type="number">
Maximum attempts per contact. Allowed range: 1–10.
</ParamField>

<ParamField formData="delay" type="number">
Time to wait between attempts to the same contact, in **minutes**. Allowed range: 5–1440.
</ParamField>

<ParamField formData="timezone" type="string">
Timezone for the campaign (e.g., "America/New_York", "Asia/Kolkata").
</ParamField>

<ParamField formData="callingHour" type="string">
JSON stringified object defining calling hours. Example: `"{\"start\":\"09:00\",\"end\":\"17:00\"}"`.
</ParamField>

<ParamField formData="allowedDays" type="string">
JSON stringified array of day names. Example: `"[\"Monday\",\"Tuesday\",\"Wednesday\",\"Thursday\",\"Friday\"]"`.
</ParamField>

<ParamField formData="startDate" type="string">
Optional date and time (ISO 8601) to start calling. Leave out to start straight away.
</ParamField>

<ParamField formData="holidayListId" type="string">
ID of a holiday list. No calls are placed on the dates in that list.
</ParamField>

<ParamField formData="pushingCrms" type="string">
JSON stringified array of destinations to send call outcomes to. Each item has `type` (`standard`, `custom`, `webhook` or `gsheet`), `schemaId` and `crmId`. Example: `"[]"`.
</ParamField>

<ParamField formData="confirmReassign" type="string">
Inbound and mixed campaigns only. Set to `"true"` to move calling numbers that are already active on another inbound campaign to this one. See the `409` error below.
</ParamField>

<RequestExample>
```bash cURL
curl --location 'https://api.weya.live/backend/api/call/upload' \
  --header 'x-api-key: YOUR_API_KEY' \
  --form 'file=@"/path/to/contacts.csv"' \
  --form 'userId="64e5f12345abcdef12345678"' \
  --form 'batchName="Marketing Campaign May 2025"' \
  --form 'batchType="outbound"' \
  --form 'callingNumbers="[\"64e5f12345abcdef87654321\"]"' \
  --form 'enableDNC="true"' \
  --form 'timezone="America/New_York"' \
  --form 'callingHour="{\"start\":\"09:00\",\"end\":\"17:00\"}"' \
  --form 'allowedDays="[\"Monday\",\"Tuesday\",\"Wednesday\",\"Thursday\",\"Friday\"]"'
```
</RequestExample>

<Note>
**CSV/Excel File Requirements:**

- Supported formats: CSV (.csv) or Excel (.xls, .xlsx)
- Must include a header row
- Must include `phoneNumber` column (required)
- Must include all mandatory variables defined by the agent
- CSV headers should match agent variable keys (e.g., `phoneNumber`, `name`, `account_id`, `custom_field_1`)
- The `phoneNumber` column is required; all other columns are flexible based on your agent's needs
- Extra columns are stored and forwarded to the agent state machine
- File encoding should be UTF-8
- Empty files or files with no valid rows will be rejected

**File Processing:**

- The system automatically detects file type by extension
- Excel files use the first sheet
- Invalid rows are identified and reported (unless `type="true"`)
- Data is normalized and validated against agent requirements
- Phone numbers are deduplicated (only the first occurrence is kept)
</Note>

## Response
<ResponseExample>
```json 200 OK
{
  "message": "",
  "status": true,
  "code": 200,
  "errorMessage": "",
  "data": {
    "batch": [
      {
        "_id": "64e5f12345abcdef98765432",
        "batchName": "Marketing Campaign May 2025",
        "callingNumbers": ["64e5f12345abcdef87654321"],
        "totalCalls": 100
      }
    ],
    "uuid": "3f6c2a1e-8b4d-4f7a-9c1e-2d5b7a9e0f11"
  }
}
```
</ResponseExample>

<ResponseField name="data.batch" type="array[object]" required>
The created campaign. The campaign ID is `data.batch[0]._id`.
</ResponseField>

<ResponseField name="data.uuid" type="string" required>
ID of this upload. Pass it as `uuid` to **Start Campaign** to start calling these contacts.
</ResponseField>

## Error Handling

- **400 Bad Request** – Missing file, empty CSV, invalid `batchType`, invalid User ID format, missing required fields, or unsupported file type.
- **404 Not Found** – User not found, organization not found, no agent found for calling numbers, or no language configured for agent.
- **400 Bad Request (invalid rows)** – The file has invalid rows and `type` is `"false"`. `data` contains `code: "INVALID_CSV_ROWS"`, `totalInvalidRows`, `validRows`, `truncated` and `invalidRows` (each `{ rowNumber, phoneNumber, reason }`). Fix the rows, or resend with `type="true"` to skip them.
- **401 Unauthorized** – Missing or invalid API key.
- **409 Conflict** – Inbound and mixed campaigns only. A calling number is already active on another inbound campaign. `data.conflicts` lists each number. Resend with `confirmReassign="true"` to move it.
- **500 Internal Server Error** – File parsing failed, database error, or other server errors.

<Check>
Then call `POST /api/call/start-calling` with the campaign ID and `data.uuid` to start calling. Use `GET /api/call/batch-details/{batchId}` to confirm the imported rows match the expected total.
</Check>
