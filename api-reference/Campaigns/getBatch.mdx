---
title: "Get Campaigns"
description: "Retrieve a paginated list of all campaigns for an authenticated user with search capabilities."
api: "GET /api/call/batches/{userId}"
---

## Overview
This endpoint lists every campaign created by the authenticated user with pagination and search support. Only non-deleted campaigns are returned by default. Use this to monitor active campaigns, view campaign summaries, and track campaign statistics.

## Prerequisites
- An API key for your workspace
- The user must own the campaigns being retrieved.

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="userId" type="string" required>
Your user ID. Campaigns are always returned for the account that owns the API key.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page number for pagination.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Number of campaigns to return per page (default: 10).
</ParamField>

<ParamField query="statusFilter" type="string">
Filter by status. Voice campaigns: `active`, `inactive`, `completed` or `all`. Video and WhatsApp campaigns: `active` or `inactive`.
</ParamField>

<ParamField query="channel_type" type="string">
Only return campaigns of this type: `voice`, `video`, `whatsapp` or `web_chat`. If omitted, campaigns of every type are returned.
</ParamField>

<ParamField query="includeDeleted" type="boolean" default="false">
Set to `true` to also return deleted campaigns.
</ParamField>

<ParamField query="search" type="string">
Search term to filter campaigns by `batchName` or `queue_status`.
</ParamField>

<RequestExample>
```bash cURL
curl --location 'https://api.weya.live/backend/api/call/batches/64e5f12345abcdef12345678?page=1&limit=10&search=Marketing' \
  --header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

## Error Handling

- **400 Bad Request** – Invalid `userId` format or invalid query parameters.
- **404 Not Found** – No campaigns found for the authenticated user.
- **500 Internal Server Error** – Failed to fetch campaign data; retry or contact support.

<Note>
**Filtering Behavior:**

- Deleted campaigns are left out unless you pass `includeDeleted=true`
- Use the `search` parameter to filter by campaign name or queue status
- Results are sorted by creation date in descending order (newest first)
- Pagination helps manage large lists of campaigns efficiently
</Note>

<Tip>
Combine this endpoint with `GET /api/call/batch-details/{batchId}` to first get an overview of all campaigns, then drill down into specific campaign details.
</Tip>
