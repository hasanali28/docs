---
title: "Get Campaigns"
description: "Retrieve a paginated list of your campaigns, with search and status filters."
api: "GET /api/call/batches/{userId}"
---

## Overview

List the campaigns created by the user who owns the API key. Deleted campaigns are never returned. Results are paginated and sorted by last update, newest first.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
  Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="userId" type="string" required>
  Your user ID. The path needs a value, but it isn't used to filter: campaigns are always returned for the user who owns the API key.
</ParamField>

<ParamField query="page" default="1" type="integer">
  Page number.
</ParamField>

<ParamField query="limit" default="10" type="integer">
  Number of campaigns per page.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive text matched against the campaign name and `queue_status`. Partial matches are returned.
</ParamField>

<ParamField query="channel_type" type="string">
  Only return campaigns of this channel: `voice`, `video`, `whatsapp` or `web_chat`. If omitted, campaigns of every channel are returned.
</ParamField>

<ParamField query="statusFilter" type="string">
  Filter by a group of statuses. What each value matches depends on `channel_type`:

  - **Voice** (or `channel_type` omitted):
    - `active` – `in-progress`, plus `completed` campaigns updated in the last 2 hours. `in-progress` campaigns are listed first.
    - `inactive` – `pending`, `paused`, `freezed` or `failed`.
    - `completed` – `completed` campaigns last updated more than 2 hours ago.
  - **Video and web chat**: `active` (link not revoked) or `inactive` (link revoked).
  - **WhatsApp**: `active` or `inactive`.

  Any other value, or no value, returns every status.
</ParamField>

<ParamField query="status" type="string">
  Only return campaigns with exactly this `queue_status`, for example `paused`.
</ParamField>

<ParamField query="type" type="string">
  Only return campaigns of this type: `outbound`, `inbound` or `mixed`.
</ParamField>

<ParamField query="createdAtMin" type="string">
  Only return campaigns created at or after this date (ISO 8601).
</ParamField>

<ParamField query="createdAtMax" type="string">
  Only return campaigns created at or before this date (ISO 8601).
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/call/batches/64e5f12345abcdef12345678?page=1&limit=10&channel_type=voice&search=Marketing' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data.batches" type="array[object]" required>
  The campaigns on this page.
</ResponseField>

<ResponseField name="data.batches[]._id" type="string" required>
  Campaign ID.
</ResponseField>

<ResponseField name="data.batches[].batchName" type="string" required>
  Campaign name.
</ResponseField>

<ResponseField name="data.batches[].type" type="string">
  Campaign type: `outbound`, `inbound` or `mixed`.
</ResponseField>

<ResponseField name="data.batches[].channel_type" type="string">
  Channel, for video, WhatsApp and web chat campaigns. Voice campaigns may not have this field.
</ResponseField>

<ResponseField name="data.batches[].queue_status" type="string" required>
  Campaign status. For voice campaigns: `pending`, `in-progress`, `paused`, `freezed` (outside the calling window), `completed` or `failed`.
</ResponseField>

<ResponseField name="data.batches[].totalCalls" type="integer">
  Number of contacts (leads) in the campaign.
</ResponseField>

<ResponseField name="data.batches[].callsPicked" type="integer">
  Legacy counter of dials placed. Use `callStats` instead.
</ResponseField>

<ResponseField name="data.batches[].callsCompleted" type="integer">
  Legacy counter of dials that lasted 10 seconds or more. Use `callStats` instead.
</ResponseField>

<ResponseField name="data.batches[].callStats" type="object">
  Per-contact call statistics for the campaign's whole history. They are updated every few minutes, so recent calls may not be counted yet. Missing when no statistics are available yet.

  - `leads` – contacts counted in the statistics
  - `leadsConnected` – of those, contacts with a connected call
  - `connectivityPct` – `leadsConnected` as a percentage of `leads`
  - `dials` – total call attempts
  - `basis` – always `lead`
  - `legacy` – the `totalCalls`, `callsPicked` and `callsCompleted` counters
</ResponseField>

<ResponseField name="data.batches[].createdAt" type="string">
  When the campaign was created (ISO 8601).
</ResponseField>

<ResponseField name="data.batches[].updatedAt" type="string">
  When the campaign was last updated (ISO 8601).
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
  Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`. `page` and `limit` are returned as strings when you pass them in the query.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

When no campaign matches, the response is `200` with an empty `batches` array.

<Tip>
  Use `GET /api/call/batch-details/{batchId}` to get the details and calls of one campaign.
</Tip>
