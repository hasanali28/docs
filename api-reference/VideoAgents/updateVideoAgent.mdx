---
title: "Update Video Agent"
description: "Update the configuration of an existing Video Agent."
api: "PATCH /api/video-agents/{id}"
---

## Overview

Update the configuration of an existing Video Agent. Send only the fields you want to change; other settings stay as they are.

## Prerequisites

- An API key for your workspace
- Valid Video Agent ID

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
Unique identifier of the Video Agent.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PATCH 'https://api.weya.live/backend/api/video-agents/6891a23bc456def789123456' \
--header 'x-api-key: YOUR_API_KEY' \
--header 'Content-Type: application/json' \
--data '{
  "agent_name": "Updated Sales Video Agent",
  "startMessage": "Hello! Welcome back. How may I assist you today?",
  "systemMessage": "You are an experienced AI sales consultant."
}'
```

</RequestExample>

### Request Parameters

<ParamField body="agent_name" type="string">
New name for the video agent.
</ParamField>

<ParamField body="avatar" type="string">
ID of the avatar shown on screen.
</ParamField>

<ParamField body="gender" type="string">
Avatar gender: `Male` or `Female`. Used to pick matching voices.
</ParamField>

<ParamField body="voice" type="string">
ID of the voice the agent speaks with. Get the options from `GET /api/video-agents/voices`.
</ParamField>

<ParamField body="enable_input_video" type="boolean">
Set to `true` to let the agent see the visitor's camera.
</ParamField>

<ParamField body="selectedLanguage" type="array[string]">
Languages the agent can speak. At least one.
</ParamField>

<ParamField body="startMessage" type="string">
Greeting spoken when the conversation begins.
</ParamField>

<ParamField body="systemMessage" type="string">
Instructions that define the agent's behavior.
</ParamField>

<ParamField body="rag" type="object">
Knowledge base to answer from: `{ "vectorDBCollection": "<knowledge base vectorDbCollection>" }`. Use the `vectorDbCollection` value from **Get Knowledge Bases**.
</ParamField>

<ParamField body="call_metrics" type="array[object]">
Data to extract after each conversation. Each item has `metric_name`, `type`, an optional `description` and optional `call_outcome_ids`.
</ParamField>

<ParamField body="callSetting" type="object">
Conversation settings, including `callTimeout` (2–60 minutes), `voiceSpeed` (0.7–1.2), `vocabulary` (array of words), `auto_detect_language` and `llmConfigs` (`temperature`, `top_p`, `max_tokens`, `frequency_penalty`, `presence_penalty`).
</ParamField>

</ResponseField>

</ResponseField>

</ResponseField>

Languages the agent can speak.
</ResponseField>

Current status of the Video Agent.
</ResponseField>

<ResponseField name="data.updatedAt" type="string">
Timestamp indicating when the Video Agent was last updated.
</ResponseField>

## Error Handling

| Status | Description |
|---------|-------------|
|400|Invalid request body or Video Agent ID|
|401|Missing or invalid API key|
|403|You do not have permission to update this Video Agent|
|404|Video Agent not found|
|500|Internal server error|

<Note>

Only the fields included in the request body are updated. Any omitted fields retain their existing values.

</Note>

<Check>

After updating the Video Agent, you can retrieve the latest configuration using:

- `GET /api/video-agents/{id}`

</Check>
