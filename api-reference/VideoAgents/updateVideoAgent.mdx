## Overview

Update a video agent created by the user who owns the API key. Send only the fields you want to change; other settings keep their values. Nested objects such as `callSetting` are merged, not replaced. Fields not listed below are ignored.

## Prerequisites

- An API key for your workspace
- The video agent's ID, from [Get Video Agents](/api-reference/VideoAgents/getVideoAgents)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the video agent.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PATCH 'https://api.weya.live/backend/api/video-agents/6891a23bc456def789123456' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "agent_name": "Updated Sales Video Agent",
    "startMessage": "Hello! Welcome back. How may I assist you today?"
  }'
```

</RequestExample>

### Request Parameters

All fields are optional. They are described in [Create Video Agent](/api-reference/VideoAgents/createVideoAgent).

| Field | Description |
| --- | --- |
| `agent_name` | Name. Can't be empty |
| `systemMessage` | Instructions. Can't be empty |
| `startMessage` | Greeting |
| `gender` | `Male` or `Female` |
| `avatar` | Avatar ID |
| `voice` | Voice ID, from [Get Available Voices](/api-reference/VideoAgents/getModeAwareVoices) |
| `enable_input_video` | `true` to see the visitor's camera |
| `selectedLanguage` | Language codes |
| `rag` | `{ "vectorDBCollection": "…" }` |
| `call_metrics` | Data to extract after each conversation |
| `callSetting` | Conversation settings |

<ResponseField name="data" type="object">
The updated video agent with its full configuration.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `agent_name` or `systemMessage` is empty, a field has an invalid value, or `id` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Video agent not found`: it doesn't exist, was deleted, or wasn't created by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 video agent requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
