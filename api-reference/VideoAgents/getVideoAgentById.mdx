title: "Get Video Agent By ID"
description: "Retrieve the full configuration of one of your video agents."
api: "GET /api/video-agents/{id}"
---

## Overview

Retrieve a video agent's full configuration: instructions, greeting, avatar, voice, languages, knowledge base and conversation settings. The agent must have been created by the user who owns the API key.

## Prerequisites

- An API key for your workspace
- The video agent's ID, from [Get Video Agents](/api-reference/VideoAgents/getVideoAgents)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the video agent.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/video-agents/6891a23bc456def789123456' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid video agent ID format`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Video agent not found`: it doesn't exist, was deleted, or wasn't created by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 video agent requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
