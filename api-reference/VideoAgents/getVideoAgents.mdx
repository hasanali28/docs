---
title: "Get Video Agents"
description: "List your video agents with pagination and search."
api: "GET /api/video-agents"
---

## Overview

List the video agents created by the user who owns the API key, with summary fields. Use [Get Video Agent By ID](/api-reference/VideoAgents/getVideoAgentById) for an agent's full configuration.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="page" default="1" type="integer">
Page number.
</ParamField>

<ParamField query="limit" default="10" type="integer">
Number of video agents per page, up to 1000.
</ParamField>

<ParamField query="search" type="string">
Case-insensitive text matched against the agent name.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/video-agents?page=1&limit=10&search=sales' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

```json 200 OK
{

  "code": 200,
  "message": "Fetched successfully",

        "createdAt": "2026-07-21T09:15:00.000Z",

      }

    "pagination": {
      "total": 1,
      "page": 1,
      "limit": 10,
```

</ResponseExample>

<ResponseField name="data.agents" type="array[object]" required>
The video agents on this page: `_id`, `agent_name`, `enable_input_video`, `createdAt` and `updatedAt`.
</ResponseField>

<ResponseField name="data.agents[]._id" type="string">
Video agent ID. Use it as `videoAgentId` when creating a video campaign.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **429 Too Many Requests** – More than 1,000 video agent requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
