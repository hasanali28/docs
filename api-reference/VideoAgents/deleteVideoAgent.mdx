## Overview

Delete a video agent created by the user who owns the API key. It no longer appears in your lists and can't be retrieved or updated through the API.

The API doesn't check whether video campaigns still use the agent. Revoke or stop using those campaigns' links first.

<Warning>
  This can't be undone through the API.
</Warning>

## Prerequisites

- An API key for your workspace
- The video agent's ID, from [Get Video Agents](/api-reference/VideoAgents/getVideoAgents)

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="id" type="string" required>
ID of the video agent to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/video-agents/6891a23bc456def789123456' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Video agent deleted successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

<ResponseField name="message" type="string">
`Video agent deleted successfully`.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `id` isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Video agent not found`: it doesn't exist, is already deleted, or wasn't created by the user who owns the API key.
- **429 Too Many Requests** – More than 1,000 video agent requests in 15 minutes from your IP address.
- **500 Internal Server Error** – Unexpected server error.
