---
title: "Get Available Voices"
description: "List the voices you can give a video agent, for its camera mode and gender."
api: "GET /api/video-agents/voices"
---

## Overview

List the voices you can use for a video agent's `voice`. Agents that see the visitor's camera (`enable_input_video: true`) need a realtime voice, so by default only realtime voices are returned.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="enableInputVideo" default="true" type="string">
`true` returns only realtime voices, for agents with `enable_input_video: true`. `false` returns every voice.
</ParamField>

<ParamField query="gender" type="string">
Only return voices of this gender: `Male` or `Female`.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/video-agents/voices?enableInputVideo=false&gender=Female' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data" type="array[object]">
The voices, newest first.
</ResponseField>

<ResponseField name="data[]._id" type="string">
Voice ID. Use it as the video agent's `voice`.
</ResponseField>

<ResponseField name="data[].agent_name" type="string">
Display name of the voice.
</ResponseField>

<ResponseField name="data[].gender" type="string">
`Male`, `Female` or `Other`.
</ResponseField>

<ResponseField name="data[].languages" type="array[string]">
Language codes the voice speaks. `languageOptions` gives display details for each.
</ResponseField>

<ResponseField name="data[].is_realtime" type="boolean">
`true` for voices that work with `enable_input_video: true`.
</ResponseField>

<ResponseField name="data[].isPremium" type="boolean">
Whether the voice is a premium voice.
</ResponseField>

<ResponseField name="data[].audioUrls" type="object">
Sample audio for each language.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `enableInputVideo` isn't `true` or `false`, or `gender` isn't `Male` or `Female`.
- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.
