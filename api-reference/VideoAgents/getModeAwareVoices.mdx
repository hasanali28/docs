---
title: "Get Available Voices"
description: "Retrieve the list of voices supported for Video Agents for the selected camera mode and avatar gender."
api: "GET /api/video-agents/voices"
---

## Overview

Retrieve all available voices that can be used when creating or updating a Video Agent. The response may vary depending on the selected video generation mode, allowing your application to display only compatible voices.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField query="enableInputVideo" type="boolean" required>
`true` if the agent will see the visitor's camera (`enable_input_video`). Only voices that work in that mode are returned.
</ParamField>

<ParamField query="gender" type="string">
Only return voices for this avatar gender: `Male` or `Female`.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/video-agents/voices?enableInputVideo=false&gender=Female' \
--header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="status" type="boolean">
Indicates whether the request completed successfully.
</ResponseField>

<ResponseField name="code" type="integer">
HTTP status code returned by the API.
</ResponseField>

<ResponseField name="message" type="string">
Success message returned by the API.
</ResponseField>

<ResponseField name="data" type="array">
Collection of voices available for the selected video mode.
</ResponseField>

<ResponseField name="data.id" type="string">
Unique identifier of the voice.
</ResponseField>

<ResponseField name="data.name" type="string">
Display name of the voice.
</ResponseField>

<ResponseField name="data.selectedLanguage" type="array[string]">
Languages the agent can speak.
</ResponseField>

<ResponseField name="data.gender" type="string">
Gender of the voice.
</ResponseField>

<ResponseField name="data.provider" type="string">
Voice provider used by the platform.
</ResponseField>

## Error Handling

| Status | Description |
|---------|-------------|
|400|Missing or invalid `enableInputVideo`|
|401|Missing or invalid API key|
|500|Internal server error|

<Note>

The available voices may differ depending on the selected video generation mode and the configured speech provider.

</Note>

<Check>

Use the returned **Voice ID** when creating or updating a Video Agent.

</Check>
