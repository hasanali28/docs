---

## Overview

List the phone numbers added by the user who owns the API key, including their telephony provider and the inbound and outbound agents assigned to them. Results are paginated and sorted newest first.

Use a number's `_id` as a `callingNumbers` entry when you create or [update a campaign](/api-reference/Campaigns/updateBatch).

To see which inbound campaign each number is active on, use [Get Phone Numbers with Agents](/api-reference/PhoneNumbers/getPhoneNumbersWithAgent).

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField path="/api/call/get-phone/{userId}" method="GET">
</ParamField>

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="userId" type="string" required>
Your user ID. The path needs a value, but it isn't used to filter: numbers are always returned for the user who owns the API key.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page number.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Number of phone numbers per page, from 1 to 1000.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive text to match against the phone number, telephony provider, SIP host or SIP username. Partial matches are returned. Example: `9876` or `plivo`.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/call/get-phone/64e5f12345abcdef12345678?page=1&limit=50' \
  --header 'x-api-key: YOUR_API_KEY'
```

```bash cURL (search)
curl --location 'https://api.weya.live/backend/api/call/get-phone/64e5f12345abcdef12345678?search=plivo' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data.phones" type="array[object]" required>
The phone numbers on this page.
</ResponseField>

<ResponseField name="data.phones[]._id" type="string">
Phone number ID. Use it in `callingNumbers` when creating or updating a campaign.
</ResponseField>

<ResponseField name="data.phones[].phoneNumber" type="string">
The phone number. SIP connections are identified by `sipFromUser` and `sipHost`.
</ResponseField>

<ResponseField name="data.phones[].integration" type="string">
Telephony provider: `twilio`, `plivo`, `telnyx`, `sip`, `jambonz`, `elisiontec`, `nexmo` or `vobiz`.
</ResponseField>

<ResponseField name="data.phones[].userId" type="string">
ID of the user who added the number.
</ResponseField>

<ResponseField name="data.phones[].createdAt" type="string">
When the number was added (ISO 8601).
</ResponseField>

<ResponseField name="data.phones[].inboundAgentId" type="string">
ID of the agent that answers incoming calls on this number, if any. When the number is pinned to an agent version, this is the version's ID.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentId" type="string">
ID of the agent that places outgoing calls from this number, if any. When the number is pinned to an agent version, this is the version's ID.
</ResponseField>

<ResponseField name="data.phones[].inboundAgentName" type="string | null">
Name of the inbound agent. `null` when no inbound agent is assigned.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentName" type="string | null">
Name of the outbound agent. `null` when no outbound agent is assigned.
</ResponseField>

<ResponseField name="data.phones[].inboundAgentVersion" type="integer | null">
Version of the inbound agent the number uses: the pinned version, or the agent's latest version when the number follows the latest. `null` when no inbound agent is assigned.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentVersion" type="integer | null">
  Version of the outbound agent the number uses: the pinned version, or the agent's latest version when the number follows the latest. `null` when no outbound agent is assigned.
</ResponseField>

<ResponseField name="data.phones[].inboundAgentRootId" type="string | null">
  ID of the inbound agent itself. It differs from `inboundAgentId` when the number is pinned to a version. Use it with the Agents endpoints.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentRootId" type="string | null">
  ID of the outbound agent itself. It differs from `outboundAgentId` when the number is pinned to a version. Use it with the Agents endpoints.
</ResponseField>

<ResponseField name="data.phones[].sipHost" type="string">
  SIP connections only: SIP host. The other SIP fields returned are `sipPort`, `sipUsername` and `sipFromUser`.
</ResponseField>

<ResponseField name="data.phones[].jambonzCarrierName" type="string">
  jambonz numbers only: name of the SIP carrier. The other jambonz fields returned are `jambonzCarrierId` and `jambonzPhoneNumberSid`.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Check>

After listing your phone numbers, you can:

- `GET /api/call/get-phone-with-agent/{userId}` to see which inbound campaign each number is active on.
- `PUT /api/call/update-phone/{phoneId}` to update a number.
- `DELETE /api/call/delete-phone/{phoneId}` to remove a number.

</Check>
