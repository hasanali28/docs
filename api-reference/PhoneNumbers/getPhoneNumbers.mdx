## Overview

List the phone numbers connected to your workspace, including their telephony provider and the inbound and outbound agents assigned to them. Results are paginated.

To see which inbound campaign each number is active on, use **Get Phone Numbers with Agents**.

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField method="GET" path="/api/call/get-phone/{userId}" />

<Note>

Put `page` and `limit` after a `?`, as in the example. Without the `?` they are not applied and you always get the first 10 numbers.

</Note>


## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="userId" type="string" required>
Your user ID. It must be included in the path; phone numbers are always returned for the account that owns the API key.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page number.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Number of phone numbers per page, from 1 to 10.
</ParamField>


<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/call/get-phone/64e5f12345abcdef12345678?page=1&limit=10' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

<ResponseField name="data.phones" type="array[object]" required>
The phone numbers on this page.
</ResponseField>

<ResponseField name="data.phones[]._id" type="string">
Phone number ID. Use it as `callingNumbers` when creating a campaign.
</ResponseField>

<ResponseField name="data.phones[].phoneNumber" type="string">
The phone number. Empty for SIP connections, which are identified by `sipFromUser` and `sipHost`.
</ResponseField>

<ResponseField name="data.phones[].integration" type="string">
Telephony provider: `twilio`, `plivo`, `telnyx`, `sip`, `exotel`, `elisiontec`, `vobiz` or `jambonz`.
</ResponseField>

<ResponseField name="data.phones[].inboundAgentId" type="string">
ID of the agent that answers incoming calls on this number, if any.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentId" type="string">
ID of the agent that places outgoing calls from this number, if any.
</ResponseField>

<ResponseField name="data.phones[].inboundAgentName" type="string">
Name of the inbound agent.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentName" type="string">
Name of the outbound agent.
</ResponseField>

<ResponseField name="data.phones[].inboundAgentVersion" type="integer | null">
Agent version the inbound agent is pinned to. `null` means it always uses the latest version.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentVersion" type="integer | null">
Agent version the outbound agent is pinned to. `null` means it always uses the latest version.
</ResponseField>

<ResponseField name="data.phones[].sipHost" type="string">
SIP connections only: SIP host. Other SIP fields are `sipPort`, `sipUsername`, `sipFromUser`, `sipTransport` and `sipRegister`.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Check>

After listing your phone numbers, you can:

- `GET /api/call/get-phone-with-agent/{userId}` to see which inbound campaign each number is active on.
- `PUT /api/call/update-phone/{phoneId}` to update a number.
- `DELETE /api/call/delete-phone/{phoneId}` to remove a number.

</Check>
