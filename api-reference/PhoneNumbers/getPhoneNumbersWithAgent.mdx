## Overview

List the phone numbers added by the user who owns the API key, with their inbound and outbound agents and the inbound campaign each number is currently active on. Results are paginated and sorted newest first. This is the list the dashboard shows when you pick **Calling Numbers** for a campaign.

Unlike [Get Phone Numbers](/api-reference/PhoneNumbers/getPhoneNumbers), this list also includes deleted jambonz numbers.

## Prerequisites

- An API key for your workspace

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="userId" type="string" required>
Your user ID. The path needs a value, but it isn't used to filter: numbers are always returned for the user who owns the API key.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page number.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Number of phone numbers per page, from 1 to 1000.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive text to match against the phone number, telephony provider, SIP host, SIP username or SIP from user. Partial matches are returned.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/call/get-phone-with-agent/64e5f12345abcdef12345678?page=1&limit=50' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

Each phone number has the same fields as in [Get Phone Numbers](/api-reference/PhoneNumbers/getPhoneNumbers) (except `userId`), plus the inbound campaign fields below. Agent fields are left out, rather than `null`, when no agent is assigned.

<ResponseField name="data.phones[].activeInboundBatchId" type="string | null">
ID of the inbound campaign this number currently receives calls for. Left out or `null` if it isn't active on any inbound campaign.
</ResponseField>

<ResponseField name="data.phones[].activeInboundBatchName" type="string | null">
Name of that inbound campaign.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Note>

A phone number can be active on only one inbound campaign at a time. Creating an inbound campaign with [Upload Campaign CSV](/api-reference/Campaigns/uploadCSV) using a number that is already active elsewhere returns `409 Conflict` unless you send `confirmReassign: "true"`.

</Note>
