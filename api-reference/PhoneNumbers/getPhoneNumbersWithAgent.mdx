---

## Overview

List your phone numbers together with the names of their inbound and outbound agents, and the inbound campaign each number is currently active on. This is the list the dashboard shows when you pick **Calling Numbers** for a campaign.

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField method="GET" path="/api/call/get-phone-with-agent/{userId}" />

<Note>

Put `page` and `limit` after a `?`, as in the example. Without the `?` they are not applied and you always get the first 10 numbers.

</Note>


## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="userId" type="string" required>
Your user ID. It must be included in the path; phone numbers are always returned for the account that owns the API key.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page number.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Number of phone numbers per page, from 1 to 10.
</ParamField>


<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/call/get-phone-with-agent/64e5f12345abcdef12345678?page=1&limit=10' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

        "outboundAgentName": "Sales Agent",

</ResponseExample>

Each phone number has the same fields as in **Get Phone Numbers**, plus:

<ResponseField name="data.phones[].inboundAgentName" type="string">
Name of the agent that answers incoming calls on this number.
</ResponseField>

<ResponseField name="data.phones[].outboundAgentName" type="string">
Name of the agent that places outgoing calls from this number.
</ResponseField>

<ResponseField name="data.phones[].activeInboundBatchId" type="string | null">
ID of the inbound campaign this number currently receives calls for. `null` if it isn't active on any inbound campaign.
</ResponseField>

<ResponseField name="data.phones[].activeInboundBatchName" type="string | null">
Name of that inbound campaign.
</ResponseField>

<ResponseField name="data.pagination" type="object" required>
Pagination details: `total`, `page`, `limit`, `totalPages`, `hasNextPage` and `hasPrevPage`.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Note>

A phone number can be active on only one inbound campaign at a time. Creating or updating an inbound campaign with a number that is already active elsewhere returns `409 Conflict` unless you send `confirmReassign: true`.

</Note>
