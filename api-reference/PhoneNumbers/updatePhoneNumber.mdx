title: "Update Phone Number"

api: "PUT /api/call/update-phone/{phoneId}"
---

## Overview

Update the details of a phone number connected to your workspace, such as its provider credentials or SIP connection settings. To change which agent handles a number, assign the agent from the dashboard's **Phone Numbers** page.

## Prerequisites

- An API key for your workspace
- The phone number's ID (`_id` from **Get Phone Numbers**)

## Endpoint

<ParamField method="PUT" path="/api/call/update-phone/{phoneId}" />

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="phoneId" type="string" required>
ID of the phone number to update.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/call/update-phone/6872d4b5f8d7a91234567890' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "userId": "64e5f12345abcdef12345678",
    "integration": "plivo",
    "phoneNumber": "+919876543210",
    "accSId": "YOUR_PROVIDER_ACCOUNT_ID",
    "authToken": "YOUR_PROVIDER_AUTH_TOKEN"
}'
```

</RequestExample>

### Request Parameters

<ParamField body="userId" type="string" required>
Your user ID.
</ParamField>

<ParamField body="integration" type="string" required>
Telephony provider: `twilio`, `plivo`, `telnyx`, `sip`, `exotel`, `elisiontec`, `vobiz` or `jambonz`.
</ParamField>

<ParamField body="phoneNumber" type="string">
The phone number, with country code. Not used for SIP connections.
</ParamField>

<ParamField body="accSId" type="string">
Account ID from your telephony provider.
</ParamField>

<ParamField body="authToken" type="string">
Auth token from your telephony provider.
</ParamField>

<ParamField body="sipHost" type="string">
SIP only: SIP server host.
</ParamField>

<ParamField body="sipPort" type="integer">
SIP only: SIP server port.
</ParamField>

<ParamField body="sipUsername" type="string">
SIP only: SIP username.
</ParamField>

<ParamField body="sipSecret" type="string">
SIP only: SIP password.
</ParamField>

<ParamField body="sipFromUser" type="string">
SIP only: the "from" user for outgoing calls.
</ParamField>

<ParamField body="sipTransport" type="string">
SIP only: `udp`, `tcp` or `tls`.
</ParamField>

<ParamField body="sipRegister" type="boolean">
SIP only: whether to register with the SIP server.
</ParamField>

<ParamField body="elisiontecListId" type="string">
Elisiontec only: list ID.
</ParamField>

## Error Handling

- **400 Bad Request** – Invalid or missing fields.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – The phone number does not exist in your workspace.
- **500 Internal Server Error** – Unexpected server error.
