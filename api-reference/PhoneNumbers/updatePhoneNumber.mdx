## Overview

Update the details of one of your phone numbers, such as its provider credentials or SIP connection settings. Send only the fields you want to change; the values are saved as sent.

Unlike **Add Phone Number**, this endpoint doesn't check credentials with the provider or set up call events again. Make sure new credentials are correct before you save them.

To change which agent handles a number, assign the agent from the dashboard's **Phone Numbers** page.

## Prerequisites

- An API key for your workspace
- The phone number's ID (`_id` from [Get Phone Numbers](/api-reference/PhoneNumbers/getPhoneNumbers)). The number must have been added by the user who owns the API key.

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="phoneId" type="string" required>
ID of the phone number to update.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/call/update-phone/6872d4b5f8d7a91234567890' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "accSId": "YOUR_PROVIDER_ACCOUNT_ID",
    "authToken": "YOUR_PROVIDER_AUTH_TOKEN"
}'
```

</RequestExample>

### Request Parameters

All fields are optional. `_id`, `userId`, `organization`, `createdAt` and `updatedAt` are ignored if sent.

<ParamField body="phoneNumber" type="string">
The phone number, with `+` and country code. Not used for SIP connections.
</ParamField>

<ParamField body="accSId" type="string">
Account ID from your telephony provider.
</ParamField>

<ParamField body="authToken" type="string">
Auth token or API key from your telephony provider.
</ParamField>

<ParamField body="sipHost" type="string">
SIP only: SIP server host.
</ParamField>

<ParamField body="sipPort" type="integer">
SIP only: SIP server port.
</ParamField>

<ParamField body="sipUsername" type="string">
SIP only: SIP username.
</ParamField>

<ParamField body="sipSecret" type="string">
SIP only: SIP password.
</ParamField>

<ParamField body="sipFromUser" type="string">
SIP only: the "from" user for outgoing calls.
</ParamField>

<ParamField body="sipTransport" type="string">
SIP only: `udp`, `tcp` or `tls`.
</ParamField>

<ParamField body="sipRegister" type="boolean">
SIP only: whether to register with the SIP server.
</ParamField>

<ParamField body="elisiontecListId" type="string">
Elisiontec only: list ID.
</ParamField>

The updated phone number record. It also contains the stored credentials, so don't log the response.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Phone ID`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Phone not found`: the number doesn't exist or wasn't added by the user who owns the API key.
- **500 Internal Server Error** – Unexpected server error.
