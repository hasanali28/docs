## Overview

Create a webhook. Once it's added to a campaign under **Track Call Outcomes** (`pushingCrms` with `type: "webhook"`), the results of each call in that campaign are sent to its URL as a JSON `POST` request.

Each organization can have up to 5 webhooks.

## Prerequisites

- An API key for your workspace
- A public HTTPS URL that accepts `POST` requests

## Endpoint

<ParamField method="POST" path="/api/webhooks" />

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/webhooks' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Salesforce CRM Sync",
    "url": "https://your-domain.com/webhook",
    "bearerToken": "YOUR_ENDPOINT_TOKEN"
}'
```

</RequestExample>

### Request Parameters

<ParamField body="name" type="string">
A friendly name to identify the webhook.
</ParamField>

<ParamField body="url" type="string" required>
URL that call outcomes are sent to, as a JSON `POST` request.
</ParamField>

<ParamField body="bearerToken" type="string">
Optional. If your endpoint requires authentication, set its token here. It is sent as `Authorization: Bearer <token>` with each request.
</ParamField>

## Response

<ResponseExample>

```json 201 Created
{
  "status": true,
  "code": 201,
  "message": "",
  "errorMessage": "",
  "data": {
    "_id": "6890abc123456789abcdef01",
    "name": "Salesforce CRM Sync",
    "url": "https://your-domain.com/webhook",
    "isActive": true,
    "createdAt": "2026-07-20T12:45:00.000Z",
    "updatedAt": "2026-07-20T12:45:00.000Z"
  }
}
```

</ResponseExample>

<ResponseField name="data" type="object" required>
The new webhook. `data._id` is the ID to use as `crmId` in a campaign's `pushingCrms`.
</ResponseField>

## Error Handling

- **400 Bad Request** – Missing or invalid `url`, or your organization already has 5 webhooks.
- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.

<Check>

After creating a webhook, add it to a campaign with `pushingCrms: [{ "type": "webhook", "crmId": "<webhook _id>", "schemaId": "<webhook _id>" }]` when creating or updating the campaign.

</Check>
