---
title: "Delete Webhook"
description: "Delete a webhook and stop sending call outcomes to it."
api: "DELETE /api/webhooks/{webhookId}"
---

## Overview

Permanently delete a webhook from your organization. It stops in every campaign that uses it at once: calls that end afterwards are not sent to it.

Deliveries already queued before the deletion, including scheduled retries, can still be sent.

## Prerequisites

- An API key for your workspace
- The webhook's ID (`_id` from [Get Webhooks](/api-reference/Webhooks/getWebhooks))

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="webhookId" type="string" required>
ID of the webhook to delete.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/webhooks/6890abc123456789abcdef01' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Webhook deleted successfully",
  "errorMessage": null,
  "data": []
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
`true` when the webhook was deleted.
</ResponseField>

<ResponseField name="message" type="string" required>
`Webhook deleted successfully`.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Webhook not found or unauthorized`: the webhook doesn't exist in your organization.
- **500 Internal Server Error** – Unexpected server error, including a `webhookId` that isn't a valid ID.

<Warning>

This can't be undone. To stop a webhook in only one campaign, remove it from that campaign's `pushingCrms` with [Update Campaign](/api-reference/Campaigns/updateBatch) instead.

</Warning>
