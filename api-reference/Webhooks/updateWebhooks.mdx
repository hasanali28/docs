---
title: "Update Webhook"
description: "Change a webhook's name, URL or bearer token."
api: "PUT /api/webhooks/{webhookId}"
---

## Overview

Update a webhook in your organization. Send only the fields you want to change; at least one is required.

## Prerequisites

- An API key for your workspace
- The webhook's ID (`_id` from [Get Webhooks](/api-reference/Webhooks/getWebhooks))

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="webhookId" type="string" required>
ID of the webhook to update.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.weya.live/backend/api/webhooks/6890abc123456789abcdef01' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "url": "https://your-domain.com/webhook/v2"
}'
```

</RequestExample>

### Request Parameters

<ParamField body="name" type="string">
New name for the webhook.
</ParamField>

<ParamField body="url" type="string">
New URL to send call outcomes to. Must be a valid `http` or `https` URL.
</ParamField>

<ParamField body="bearerToken" type="string">
New token to send as `Authorization: Bearer <token>`. Send an empty string to stop sending one.
</ParamField>

<ParamField body="isActive" type="boolean">
  Stored flag only. Setting it to `false` does **not** stop deliveries. To stop a webhook, remove it from the campaign's `pushingCrms` with [Update Campaign](/api-reference/Campaigns/updateBatch), or delete it.
</ParamField>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Webhook updated successfully",
  "errorMessage": null,
  "data": {
    "_id": "6890abc123456789abcdef01",
    "name": "Salesforce CRM Sync",
    "url": "https://your-domain.com/webhook/v2",
    "isActive": true,
    "updatedAt": "2026-11-19T09:00:00.000Z"
  }
}
```

</ResponseExample>

<ResponseField name="data" type="object" required>
The updated webhook, including its `bearerToken`.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `No updatable fields provided`, `Invalid Webhook URL format`, `Invalid protocol. Only http and https are allowed.`, or a `webhookId` that isn't a valid ID.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Webhook not found or unauthorized`: the webhook doesn't exist in your organization.
- **500 Internal Server Error** – Unexpected server error.
