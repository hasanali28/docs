title: "Get Webhooks"

---

## Overview

List the webhooks in your organization. A webhook is a URL that call outcomes are sent to: add it to a campaign under **Track Call Outcomes** (`pushingCrms` with `type: "webhook"`), and the results of each call are sent to it as a JSON `POST` request.

Each organization can have up to 5 webhooks.

## Prerequisites

- An API key for your workspace

## Endpoint

<ParamField method="GET" path="/api/webhooks" />

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<RequestExample>

```bash cURL
curl --location 'https://api.weya.live/backend/api/webhooks' \
  --header 'x-api-key: YOUR_API_KEY'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "",
  "errorMessage": "",
  "data": [
    {
      "_id": "6890abc123456789abcdef01",
      "name": "Salesforce CRM Sync",
      "url": "https://your-domain.com/webhook",
      "userId": "64e5f12345abcdef12345678",
      "organizationId": "64e5f12345abcdef00000001",
      "isActive": true,
      "createdAt": "2026-07-20T12:45:00.000Z",
      "updatedAt": "2026-07-20T12:45:00.000Z"
    }
```

</ResponseExample>

<ResponseField name="data" type="array[object]" required>
The webhooks in your organization.
</ResponseField>

<ResponseField name="data[]._id" type="string">
Webhook ID. Use it as `crmId` in a campaign's `pushingCrms`.
</ResponseField>

<ResponseField name="data[].name" type="string">
Name of the webhook.
</ResponseField>

<ResponseField name="data[].url" type="string">
URL that call outcomes are sent to.
</ResponseField>

<ResponseField name="data[].bearerToken" type="string">
Token sent as `Authorization: Bearer <token>` with each request, if one was set.
</ResponseField>

<ResponseField name="data[].isActive" type="boolean">
Whether the webhook is active.
</ResponseField>

## Error Handling

- **401 Unauthorized** – Missing or invalid API key.
- **500 Internal Server Error** – Unexpected server error.
