---
title: "Delete Phone Number"
description: "Permanently remove a phone number from your workspace."
api: "DELETE /api/call/delete-phone/{phoneId}"
---

## Overview
Permanently delete a phone number you no longer use. It is removed from your phone number lists and can't be selected for new campaigns.

The number is not removed from campaigns that already use it, and the API doesn't check for them. Campaigns that call from a deleted number can't place calls or retries from it.

## Prerequisites
- An API key for your workspace
- The phone number's ID (`_id` from [Get Phone Numbers](/api-reference/PhoneNumbers/getPhoneNumbers)). The number must have been added by the user who owns the API key.
- Remove the number from any running campaign first with [Update Campaign](/api-reference/Campaigns/updateBatch).

## Request

<ParamField header="x-api-key" type="string" required>
Your workspace API key. Create one from the profile menu in the dashboard → **API Keys**.
</ParamField>

<ParamField path="phoneId" type="string" required>
  ID of the phone number to delete.
</ParamField>

<RequestExample>
```bash cURL
curl --location --request DELETE 'https://api.weya.live/backend/api/call/delete-phone/64e5f12345abcdef87654321' \
  --header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

## Response
<ResponseExample>
```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Phone deleted successfully",
  "errorMessage": null,
  "data": {
    "deletedId": "64e5f12345abcdef87654321"
  }
}
```
</ResponseExample>

<ResponseField name="data.deletedId" type="string" required>
ID of the deleted phone number.
</ResponseField>

## Error Handling

Errors return `status: false`, with the reason in `errorMessage`.

- **400 Bad Request** – `Invalid Phone ID`.
- **401 Unauthorized** – Missing or invalid API key.
- **404 Not Found** – `Phone not found`: the number doesn't exist, is already deleted, or wasn't added by the user who owns the API key.
- **500 Internal Server Error** – Unexpected server error.

<Warning>
Deletion can't be undone. To use the number again, add it again with **Add Phone Number**; it gets a new ID.
</Warning>
