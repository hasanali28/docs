---
title: "Create Voice Blaster"
description: "Create a new voice blaster for outbound voice broadcasting."
api: "POST /api/voice-blaster"
---

## Overview

Create a new Voice Blaster to broadcast pre-recorded or AI-generated voice messages to multiple recipients. After creating a Voice Blaster, you can add recipients and start the broadcast using the appropriate endpoints.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to create Voice Blasters
- A configured AI Agent (if required)
- A Phone Number configured for outbound calling

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request POST '{{baseUrl}}/api/voice-blaster' \
--header 'Authorization: Bearer {{authToken}}' \
--header 'Content-Type: application/json' \
--data '{
  "name": "Festival Campaign",
  "description": "Outbound voice broadcast for existing customers",
  "agentId": "687b1c2ab7c7d3f123456789",
  "phoneNumberId": "6889c4ab7c7d3f987654321"
}'
```

</RequestExample>

## Request Body

<ParamField body="name" type="string" required>
Name of the Voice Blaster.
</ParamField>

<ParamField body="description" type="string">
Optional description for the Voice Blaster.
</ParamField>

<ParamField body="agentId" type="string" required>
Unique identifier of the AI Agent used for the broadcast.
</ParamField>

<ParamField body="phoneNumberId" type="string" required>
Unique identifier of the outbound phone number.
</ParamField>

## Error Handling

- **400 Bad Request** – Invalid request body.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to create Voice Blasters.
- **404 Not Found** – Agent or Phone Number not found.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Creating a Voice Blaster only creates the configuration. You can upload contacts and start the broadcast using the corresponding Voice Blaster endpoints.

</Note>

<Check>

Use the returned **Voice Blaster ID** with:

- `GET /api/voice-blaster` to list all Voice Blasters.
- `GET /api/voice-blaster/{id}` to retrieve Voice Blaster details.
- `PATCH /api/voice-blaster/{id}` to update the Voice Blaster.
- `DELETE /api/voice-blaster/{id}` to delete the Voice Blaster.

</Check>
