title: "Get Voice Blasters"
description: "Retrieve all Voice Blaster agents available in your workspace."
api: "GET /api/voice-blasters"
---

## Overview

Retrieve a list of all Voice Blaster agents in your workspace. This endpoint allows you to view available Voice Blaster configurations that can be used for outbound broadcasting.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to access Voice Blasters

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField query="page" type="integer">
Page number for pagination. Default is `1`.
</ParamField>

<ParamField query="limit" type="integer">
Number of Voice Blaster agents to return per page. Default is `10`.
</ParamField>

<ParamField query="search" type="string">
Optional search term to filter Voice Blaster agents by name.
</ParamField>

<RequestExample>

```bash cURL
curl --location '{{baseUrl}}/api/voice-blasters?page=1&limit=10&search=promotion' \
  --header 'Authorization: Bearer {{authToken}}'
```

</RequestExample>

## Error Handling

- **400 Bad Request** – Invalid query parameters.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to access Voice Blaster agents.
- **500 Internal Server Error** – Unexpected server error.

<Note>

This endpoint supports **pagination** and **search**. If no search term is provided, all Voice Blaster agents in the workspace are returned.

</Note>

<Check>

Use the returned **Voice Blaster ID** with:

- `GET /api/voice-blasters/{id}` to retrieve Voice Blaster details.
- `PATCH /api/voice-blasters/{id}` to update a Voice Blaster.
- `DELETE /api/voice-blasters/{id}` to delete a Voice Blaster.

</Check>
