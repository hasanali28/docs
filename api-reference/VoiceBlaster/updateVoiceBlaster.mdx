---
title: "Update Voice Blaster"
description: "Update the configuration of an existing Voice Blaster."
api: "PATCH /api/voice-blasters/{id}"
---

## Overview

Update the configuration of an existing Voice Blaster using its unique ID.

## Prerequisites

- Bearer token for an authenticated workspace
- Permission to update Voice Blasters
- A valid Voice Blaster ID

## Request

<ParamField header="Authorization" type="string" required>
Bearer token for authenticated workspace access.
</ParamField>

<ParamField path="id" type="string" required>
Unique identifier of the Voice Blaster to update.
</ParamField>

<RequestExample>

```bash cURL
curl --location --request PATCH '{{baseUrl}}/api/voice-blasters/6895d6a7d3f7a12345678901' \
  --header 'Authorization: Bearer {{authToken}}' \
  --header 'Content-Type: application/json' \
  --data '{
    "agent_name": "Updated Promotional Campaign",
    "voice": "en-US-Standard-A",
    "description": "Updated promotional voice blaster"
  }'
```

</RequestExample>

## Response

<ResponseExample>

```json 200 OK
{
  "status": true,
  "code": 200,
  "message": "Voice Blaster updated successfully",
  "data": {
    "_id": "6895d6a7d3f7a12345678901",
    "agent_name": "Updated Promotional Campaign",
    "voice": "en-US-Standard-A",
    "conversationType": "static_voice_blaster",
    "status": "active",
    "description": "Updated promotional voice blaster",
    "createdAt": "2025-07-15T10:30:00.000Z",
    "updatedAt": "2025-07-16T09:45:00.000Z"
  }
}
```

</ResponseExample>

<ResponseField name="status" type="boolean" required>
Indicates whether the request completed successfully.
</ResponseField>

<ResponseField name="code" type="integer" required>
HTTP status code.
</ResponseField>

<ResponseField name="message" type="string" required>
Human-readable success message.
</ResponseField>

<ResponseField name="data" type="object" required>
Contains the updated Voice Blaster details.
</ResponseField>

<ResponseField name="data._id" type="string">
Unique identifier of the Voice Blaster.
</ResponseField>

<ResponseField name="data.agent_name" type="string">
Updated name of the Voice Blaster.
</ResponseField>

<ResponseField name="data.voice" type="string">
Voice assigned to the Voice Blaster.
</ResponseField>

<ResponseField name="data.conversationType" type="string">
Conversation mode configured for the Voice Blaster.
</ResponseField>

<ResponseField name="data.status" type="string">
Current status of the Voice Blaster.
</ResponseField>

<ResponseField name="data.description" type="string">
Updated description of the Voice Blaster.
</ResponseField>

<ResponseField name="data.createdAt" type="string">
Timestamp when the Voice Blaster was created.
</ResponseField>

<ResponseField name="data.updatedAt" type="string">
Timestamp when the Voice Blaster was last updated.
</ResponseField>

## Error Handling

- **400 Bad Request** – Invalid request data or Voice Blaster ID.
- **401 Unauthorized** – Missing or invalid Bearer token.
- **403 Forbidden** – You do not have permission to update this Voice Blaster.
- **404 Not Found** – Voice Blaster not found.
- **500 Internal Server Error** – Unexpected server error.

<Note>

Only the fields provided in the request are updated.

</Note>
