A weya knowledge base is a collection of your documents that an agent answers from, such as product details, policies and FAQs. One knowledge base can be attached to many agents, and one agent can use several knowledge bases.

<Steps>
  <Step title="Create a knowledge base">
    1. Go to **Knowledge Base** in the dashboard.
    2. Click **Add KB**.
    3. Enter a name and description, and attach your files.
    4. Click **Create**.
  </Step>
  <Step title="Attach it to an agent">
    1. Go to **Agents** and open the agent.
    2. Open its **Knowledge Base & Tools** settings.
    3. Select the knowledge bases the agent should use.
  </Step>
</Steps>

<Check>
  The agent now answers questions from the documents in the knowledge base.
</Check>

## Tips

- Split unrelated topics into separate knowledge bases, for example pricing and support, so each agent gets only what it needs.
- Keep documents current, and remove outdated or duplicate files that could lead to conflicting answers.
- Tell the agent in its system prompt when to rely on the knowledge base and what to say when the answer isn't there.

## Manage knowledge bases with the API

Create, update and list knowledge bases and their documents with the [Knowledge Base API](/api-reference/KnowledgeBase/getKnowledgeBases).
