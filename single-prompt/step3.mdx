Call settings control how a weya voice agent behaves on the line: which language it speaks, what happens at voicemail, how it sounds and how long a call can last.  

| Setting | What it does | When to change it |
| --- | --- | --- |
| **Auto Detect Language** | Detects the caller's language and switches to it | Turn on for multilingual audiences |
| **Retry on Voicemail** | Retries the contact when the call reaches voicemail | Turn on for important or time-sensitive outreach |
| **Ambient Noise** | Plays background sound to make the call feel more natural | Use quiet options for support, busier ones for informal calls |
| **Vocabulary** | Words the speech recognition should expect | Add names, product terms and company jargon |
| **Max Timeout** | The maximum length of a call, up to 30 minutes | Lower it to limit cost and unattended calls |
| **Voice Speed** | How fast the agent speaks. 1x is normal | Slow it down for clarity and accessibility |

## Ambient noise

- **Noise Type**: the background sound, for example `office-with-telephone`.
- **Noise Volume**: from 0 to 1. Keep it low so it doesn't distract.

## Retry on voicemail

When this is on, a call that reaches voicemail is retried like an unanswered call, using the campaign's retry limit and delay. See [Retries](/get-started/concepts#retries).

## Vocabulary

Enter each word separately. Add the terms speech recognition is most likely to get wrong: people's and place names, product names and abbreviations.
